# confidant(知己笔记)首版规格 v1

- 本规格由 wayfinder 地图 effort「confidant-v1」的**全部决议汇编**而成(issues/01–16,全程记录见 [map.md](map.md))。每项裁决的完整依据与讨论链在对应票文件的 `## Answer`。
- 详度标尺:每项裁决有结论与依据;关键交互含边界情形与文案;像素级视觉与实现技巧不在本文范围(归实现 effort)。
- 本文为**目的地产物**:实现 effort 接手即以此开工;随实现推进如需修订,按仓库 tracker 惯例记录变更。

---

## 1. 产品定义

本地优先、所见即所得(参照 Typora)的 Markdown 桌面编辑器,兼本地笔记软件:用户像打开文件夹一样进入工作区,以 WYSIWYG 方式书写与组织 `.md` 文件;数据直接落在本地磁盘、由用户自己管理。

- **产品三原则**:本地优先(数据就是磁盘上普通的 .md 文件,可带走、可备份、可被任何工具打开);所见即所得(写作与阅读一体,不打断思路);大众可用(不预设技术门槛,首开即能理解)。
- **参照基线**:Typora(仅交互参照,不是功能义务,不构成论证)。
- 名称:confidant / 知己笔记。

## 2. 目标用户与服务边界

**画像 P1**(全部为**假设**,未经调研验证;检验清单见附录 B):

| 维度 | 取值(假设) |
|---|---|
| 使用场景 | 工作与生活记录:周报、会议纪要、日记、清单、摘抄;不定期,每周至少几次 |
| 写作体量 | 单篇几百字至两三千字;累计几十至几百个文件 |
| 组织习惯 | 按主题建文件夹归档、树状管理;倾向先见全貌再决定写哪 |
| Markdown 认知 | 不知道 Markdown 语法——WYSIWYG 是其写作不被打断的前提 |
| 技术水位 | 会装软件、会用文件资源管理器;不碰命令行、不编辑配置文件 |
| 迁移来源 | Word/记事本/手机便签,无现成 md 库要导入 |
| 地域/语言 | 中国大陆;简体中文界面(单语言,不做 i18n) |

**服务边界(仲裁规则式)**:大众可用 > 极客扩展。任何人可用但不为首版优化;凡与 P1 的大众可用冲突处,按 P1 赢。示例排除:高密知识库用户(双链/图谱/插件生态需求者)、多端同步需求者。

**决策引用规则**:本文一切进/出裁决的判据均为「对 P1 的 \<场景\> 是否有价值」;规格写作不得以「Typora 有」为由补回任何被裁决为「出」的能力。

## 3. 平台与运行环境

- 目标平台:**仅 Windows**(Windows 10/11,跟随 Electron 官方支持面;Windows 7/8 无承诺)。本规格内一切条目为 Windows 单平台形态,无多平台变体。
- Linux、macOS:不在首版范围;不承诺、不规划(技术结构不主动堵死后补,规格不为它们留位)。
- 界面语言:简体中文(单语言,不做 i18n——P1 地域假设,未验证前维持)。

## 4. 数据与格式承诺

1. **源格式仅 .md**:打开、新建、树显示、搜索只认 Markdown 文件;其他源格式(.txt/.org/docx 等导入)划出。
2. **语义级保真承诺**:保存后的文件始终是标准、合法的 Markdown,任何工具可打开、可带走、可备份。编辑保存时的以下**规范化属正常行为,不承诺字节不动**:行尾 CRLF→LF(写盘统一 LF)、列表标记/分隔线风格(`-`/`*`、`---`/`***`)、表格列宽衬垫与分隔线破折号、多余空行折叠、文首空行移除。保存文本**以单个换行结尾**(TipTap 序列化丢文末换行时补)。
3. **YAML front matter 规则**:文件首部的 front matter 元数据块**原样保留**——不解析、不利用、不改写(不做导出设置、不做 root-url 等任何语义)。显示默认:以等宽源码样式文本块呈现于文档顶部(照录内容),编辑区其余行为与普通文本一致;打开→保存该块字节不变(实现首验项)。
4. **防静默丢失防御(实现验收级)**:引擎不支持或降级处理的任何语法/内容,打开→保存不得丢内容;不得静默降级(参考:TipTap 的 Image 若不显式注册,图片语法会被解析成纯文本而丢链接——Image 必须注册,见第 5 节)。违反即 bug。

## 5. 技术栈与实现基线

- Electron + React + Vite + TypeScript + **shadcn/ui**(Tailwind + Radix;壳 UI);编辑引擎 **TipTap 3.x**(ProseMirror 基底)。
- 引擎扩展**显式注册清单**(StarterKit 之外):Table / TableRow / TableCell / TableHeader、TaskList / TaskItem、**Image(必须)**;Markdown 桥(@tiptap/markdown)开启 GFM。锁小版本,桥的升级走回归测试。
- 编辑器正文渲染区与 UI 壳样式分离:壳走 shadcn 变量,正文渲染区独立 CSS(见第 12 节)。
- 功能包边界遵循仓库 deep-module 规则(packages/README.md):入口点/私有实现/禁 barrel;编辑引擎以独立包封装。
- 数据能力基线(渲染与编辑,经 06 原型实测语义级往返):标题 1–6、段落、粗体/斜体/删除线/下划线、链接、行内代码、代码块(围栏+语言)、引用、有序/无序列表、任务列表、表格、图片、分隔线、硬换行。

## 6. 启动与窗口

- **常规启动:恢复上次工作区**——直接回到上次打开的文件夹与最后编辑的文件,展开状态还原(与文件树展开记忆同源)。
- **首启/无历史:欢迎页**——产品名 + 一句人话(标语行),纯空态不陈列历史(27);打开工作区入口统一在菜单「文件 → 打开文件夹」(Ctrl+O)。
- 「打开文件夹」随时可从菜单执行,即切换工作区;切换前不丢已编辑内容(自动保存模型,见第 9 节)。
- 单窗口形态:无标签页、无托盘常驻、无状态栏、无应用内多窗口;系统标准窗口装饰(可最小化到任务栏)。
- **窗口状态记忆**:关闭时记录是否最大化与正常态大小/位置;下次启动原样恢复;保存位置与任一显示器工作区不相交时回退默认尺寸;最小化不作为持久记忆。
- 自动更新等发布工程:属于实现 effort 决策,不在本规格承诺范围。

## 7. 菜单栏(命令承载与可发现性)

菜单栏常驻可见(Windows 桌面形态),是全局命令的可发现性通道——以下命令**同时**存在于右键菜单/浮动工具条/快捷键的,一律以菜单为基准源。默认结构(各命令的来源裁决见括号):

**文件**:新建笔记(05)、打开文件夹 Ctrl+O(05)、最近打开(05)、保存 Ctrl+S(13)、导出 PDF(14)、打印(14)、退出
**编辑**:撤销 Ctrl+Z(13)、重做 Ctrl+Y(13)、剪切/复制/粘贴/删除(系统 role,显式中文)、查找 Ctrl+F(09,搜索面板·当前文件作用域)
**段落**:标题 1–6 Ctrl+1..6、正文 Ctrl+0、无序列表 Ctrl+Shift+]、有序列表 Ctrl+Shift+[、任务列表 Ctrl+Shift+9、引用 Ctrl+Shift+Q、代码块 Ctrl+Shift+K、表格 Ctrl+T(13/08 裁决的格式入口)
**格式**:加粗 Ctrl+B、斜体 Ctrl+I、删除线 Ctrl+Shift+S、链接 Ctrl+K、清除格式 Ctrl+Shift+L、插入图片… Ctrl+Shift+I(13/08/05)
**视图**:侧栏显示/隐藏(05)、全工作区搜索 Ctrl+Shift+F(09)、外观 → 跟随系统 / 浅色 / 深色(10/15)
**设置**:编辑器 → 代码块自动换行 / 代码块显示行号(28 裁决;勾选态,默认均开)
**帮助**:关于

快捷键规则:固定清单(如上),与 Windows 常规习惯一致;**不支持用户自定义键位**(属高级配置,反画像);快捷键为辅助,主入口是菜单。

## 8. 文件树与文件管理

- **形态**:左侧文件树侧栏;可收起(有可见按钮,不依赖快捷键)、宽度可拖;当前编辑文件高亮,不在可见区时自动展开定位。无工作区时侧栏以空态框体呈现,开关仍可操作(27)。
- **内容**:文件夹全显,**文件只显示 .md**;隐藏文件与杂项(以 `.` 开头或系统隐藏属性)不出现。
- **排序**:同层文件夹在前,组内按名称升序(自然序);展开/折叠状态记忆,重开还原。
- **外部变更**:自动监听文件夹,外部增删改原位即时反映(与搜索同源,见第 11 节)。
- **文件操作**(右键菜单 + 菜单栏「文件」):新建笔记、新建文件夹、重命名、删除、撤销。
  - **新建笔记**(默认名「未命名笔记.md」,重名自动加序号)——同一命令从欢迎页空态引导可达。
  - **删除**:单文件直接移入系统回收站(不弹确认);文件夹弹一次确认(文案默认:「删除文件夹及其中的全部笔记?文件将移入回收站」);删除正在编辑的文件先提示(见第 9 节外部删除处置)。
  - **撤销**(操作后提示条「已移动 / 已重命名 — 撤销」,单步):移动与重命名可撤销;删除不设撤销(回收站是恢复通道)。
  - **拖拽**:树内拖拽移动文件/文件夹(含跨文件夹)。
- **边界情形默认**:重名冲突由系统规则提示、操作不生效;只读介质/被占用文件的写操作失败时给明确提示;符号链接等少见情形遵循系统资源管理器行为。
- **空态**:工作区内没有 .md 时,编辑区显示引导文案(默认):「这个文件夹还没有笔记:右键左侧空白处可以新建,也可以把 .md 文件放进这个文件夹。」
- 图片等非 .md 文件不进树(见第 10 节补偿通道)。

## 9. 编辑体验

- **视图形态**:所见即所得单面编辑;不存在源码模式、不存在输入即转(`# `、`- ` 等语法驱动转换不做——输入的一切按字面文本处理;格式入口见下)。

### 9.1 输入与换行
- Enter = 新段落/块(按光标处块语义);Shift+Enter = 段内硬换行(保存序列化回行尾两空格形式)。
- 中文 IME 组合期间不触发保存/自动转换;IME 光标与组合体验为**实现首验项**(自动化无法覆盖)。

### 9.2 粘贴
- 富文本来源(网页/Word 复制):按语义转换——标题、列表、粗体/斜体、链接等结构保留;内容经安全白名单解析,不引入脚本/危险 HTML。
- 纯文本来源:**原样插入,不把 Markdown 语法文本解析成格式**(同事发来的 `- 事项` 文本,粘贴结果是文字)。
- 剪贴板含图片数据(截图等):走第 10 节落盘通道。
- 位图与文件路径同存的剪贴板:图片数据优先(位图落盘);文件路径对象按扩展名判断:图片 → 落盘;非图片文件 → 插入指向该文件的链接文本(不复制文件)。

### 9.3 保存模型
- **自动保存**:编辑停顿(约 1 秒防抖)后自动写盘;写盘原子化(先写临时文件再替换)原则。
- Ctrl+S 手动保存并存(Windows 肌肉记忆)。
- 关闭窗口/切换工作区不存在「未保存内容」态(自动保存已覆盖);崩溃后最多丢失最后一次防抖窗口内的键入。

### 9.4 外部变更处置
- 正在编辑的文件被外部删除/改名:编辑区顶部提示条(默认文案):「文件已被删除」+ 按钮「恢复重建」/「放弃」。**不静默重建文件**(用户主动删除不应被复活);误删/同步冲突可经「恢复重建」救回。
- 文件被外部修改:不弹窗打扰;内容变更经监视反映,以磁盘为最终真相(语义级承诺下的正常情形)。

### 9.5 格式入口(无语法门槛)
- **链接面板(29,原浮动格式工具条已移除)**:插入/修改链接的独立弹层——「格式 → 链接」Ctrl+K 呼出;光标在链接内时呼出进入编辑态(地址 + 显示文本,含「移除链接」);选中文本不再浮现任何工具条(加粗/斜体/删除线/清除格式仅经「格式」菜单与快捷键)。
- **段落/格式菜单**(第 7 节):标题层级、列表、引用、代码块、表格等块级操作从这走——不依赖语法、不依赖快捷键。

### 9.6 块级与结构化操作
- **表格**:光标在表格内 → 右键菜单增删行/列、对齐;Tab = 移下一格,表尾 Enter = 加行。
- **任务列表**:点击复选框切换完成态(写盘为 `- [x]`/`- [ ]`);列表缩进 Tab、反缩进 Shift+Tab(右键菜单同步提供)。
- 撤销/重做 Ctrl+Z / Ctrl+Y(编辑面,含格式与结构变更)。

## 10. 图片

- **插入通道(同一落盘规则)**:剪贴板粘贴位图、从资源管理器拖入图片文件、菜单「插入图片」(选文件)。
- **落盘规则(零配置,不询问)**:图片自动复制到**当前 .md 同目录**;命名 `{笔记名}-{时间戳}.png`(位图按剪贴板格式 png/jpeg)或沿用拖入源文件的扩展名;重名自动防撞;文档内写入相对路径引用。
- **渲染**:png/jpg/jpeg/gif/webp 等常见格式(Chromium 原生渲染面),GIF 动图正常播放;图片显示最大宽度 = 正文行宽,等比收缩居中(渲染层行为,不改动源文件与源语法);**不提供图形化缩放/对齐/图注**(裁决为出)。
- **图片右键菜单**:
  - 打开所在文件夹(树不显示图片文件——这是 P1 找到图片的唯一应用内通道)
  - 复制图片
  - 删除(引用与图片文件一并移入回收站;弹一次确认,默认文案:「删除这张图片及其文件?将移入回收站」)
- 图床/云上传/网络图:不做(本地优先承诺;隐私边界)。

## 11. 搜索

- **入口**:文件树顶部搜索框 + 菜单「查找 / 全工作区搜索」(Ctrl+F / Ctrl+Shift+F)。
- **作用域**:面板内切换「当前文件」/「整个工作区(全部 .md)」;首版子串匹配,不做正则/选项面板。
- **结果**:列表显示文件与命中的行摘要;点击结果 → 打开该文件(不在当前视图则切换)并滚动高亮命中处。
- **实时性**:与文件监听同源,搜索反映磁盘现状,不依赖索引。
- 占位文案(默认):「搜索笔记…」。

## 12. 外观与排版

- **深浅色**:跟随 Windows 系统色系自动切换(浅/深两套观感);视图菜单「外观」提供「跟随系统 / 浅色 / 深色」手动切换。
- **实现分层**:UI 壳(侧栏/菜单)走 shadcn 变量体系;正文渲染区独立 CSS;两套观感同源色板变量(深浅各一套,对比度满足可用性;具体色值由实现 effort 按此原则定义,不在此承诺具体色号)。
- **默认排版设计**(无用户开关;以下为默认参数,实现可按可读性微调并记录):
  - 正文区:居中布局,最大宽度约 860px(窄窗两侧留白下限 16px,27);行高 1.6–1.8(中文排版底线)。
  - 字体:中文正文系统无衬线栈(如 "Microsoft YaHei UI" / "Microsoft YaHei" 优先,西文 "Segoe UI");代码等宽栈(如 Consolas 优先)。
  - 标题:层级通过字号阶梯 + 加粗 + 间距表达;文档标题(首个 H1)起排版骨架。
  - 图片:行宽上限等比居中(第 10 节);表格、代码块、引用有独立底色/边框区分(深浅色各一套)。代码块另支持语法高亮(围栏语言已注册才高亮,不自动探测)、行号与自动换行(28;行号/换行可在「设置 → 编辑器」关闭)。
  - 打印/导出恒浅色观感(第 13 节),不随系统深浅。

## 13. 导出与打印

- **导出 PDF**:文件菜单「导出 PDF」。以当前文档渲染通道直接成 PDF(所见即所得落纸);恒浅色观感;默认 A4、常规页边距(细则实现 effort 定,不设用户导出设置)。
- **打印**:文件菜单「打印」→ 系统打印对话框;与 PDF 同一渲染通道。
- **落点与覆盖**:导出到当前 .md 同目录、同名(`{文件名}.pdf`);同名存在时**直接覆盖,无确认**——导出是生成物不是数据(源 .md 在,可随时再生成)。
- **完成后反馈**:成功提示 + 「打开所在文件夹」按钮(树不显示 .pdf,用户需要知道产物在哪)。
- **管线承诺**:导出/打印不触碰、不改写源文件;front matter 原样区按渲染所见进入导出物(所见即所得口径)。
- Pandoc 全家桶、自定义命令、变量体系、YAML 导出控制、导出设置面:不做(裁决为出/延后,见附录 A)。

## 14. 链接交互

- 单击链接文字:进入编辑态(修改链接文本/地址),**不跳转**(防误触打断写作)。
- 打开链接:右键菜单「打开链接」或 Ctrl+单击:
  - `http(s)://` → 系统默认浏览器打开;
  - 指向工作区内 `.md` 文件 → 应用内打开(切换视图,当前编辑内容已自动保存,不丢);
  - 其他本地路径(文件/文件夹)→ 在系统资源管理器中显示。
- 链接携带标题锚点(`file.md#标题`)且目标在工作区内时:打开后滚动定位到该标题。

## 附录 B:假设检验清单与实现首验清单

**画像假设检验**(执行时机:产品可用后;未验证前,本规格一切 P1 引用均为假设):
1. P1 首开能否不引导即开始书写(WYSIWYG 前提是否成立);
2. 是否出现「Markdown 是什么 / 我的文件在哪」类问题;
3. 实际单篇与文件量级是否与假设相符;
4. 简体中文单语言是否满足。

**实现首验清单**(自动化无法覆盖或原型未验,实现 effort 开工即验):
1. 真 IME 组合过程(打字/回改/标点)——TipTap 与 Milkdown 同为 ProseMirror 基底,风险对称,但必须实机验证;
2. 表格单元格编辑手感与长文滚动/渲染性能;
3. 图片粘贴落盘通道(11)端到端;
4. front matter 原样保留补测(08/06 未覆盖场景);
5. 验收:Image 显式注册 + 防静默丢内容规则(第 4 节);
6. @tiptap/markdown 桥升级回归。

## 附录 C:风险登记

1. @tiptap/markdown 桥(2025-10 发布)较新——锁版本 + 升级回归(见附录 B-6);
2. math 无官方扩展——数学公式为延后项,若未来毕业需扩展评估;
3. 语义级承诺的边界:对「字节洁癖」型用户(程序员/git diff 用户)不承诺——服务边界规则(第 2 节)已将此人群划出首版优化对象;
4. Windows DPI/高对比度等系统级可访问性组合未逐项验证——实现期以系统默认行为为准,异常登记修复。
