# 外观与主题仲裁

Type: grilling
Status: resolved

## Question

按 03 范围裁决标准的判据表(默认出、举证进;以画像 P1 为判据;与三原则相抵自动出),逐项裁决**外观与主题类候选能力**的进/延后/出:

- 深色/浅色模式(跟随系统?)
- 自定义主题(用户 CSS 主题包)
- 界面字号与字体设置
- 行宽/排版偏好设置
- 其他(候选以 12 Typora 候选清单为准,清单遗漏者按同一标准补裁)

每项产出:裁决(进/延后/出)+ 一句依据(引用 P1 的具体场景)+ 成本档(S/M/L)。

注意(02 决议):P1 技术水位假设是「不碰命令行、不编辑配置文件」——凡要求 P1 接触 CSS/配置文件才能用的能力,举证责任更重。

## Answer

**决议:v1 外观 = 浅/深两套默认观感(跟随系统)+ 默认排版设计;CSS 开放能力全部出局。**(适用 03 判据表;候选以 12 清单 C 组为准;P1 技术水位(02)= 不碰 CSS/配置文件。)

**统一裁决清单表**(进/延后/出 + 成本档 + 依据一句):

| # | 候选 | 裁决 | 成本档 | 依据 |
|---|---|---|---|---|
| H1 | 深/浅色模式(联动系统) | **进** | S | 大众 Windows 夜间/护眼习惯普及;系统深浅自动跟随是 Win10/11 常识;shadcn 变量 + 渲染 CSS 双套 |
| H2 | 自定义主题全套(主题包/编写/画廊/分层 CSS/配方库) | 出 | — | P1 不碰 CSS(02)——整套开放能力服务反画像人群;默认观感由规格正文设计锁定 |
| H3 | 正文渲染字号/字体设置 | 延后 | — | Windows DPI 全局缩放已覆盖大字;独立设置举证不足,待验证反馈 |
| H4 | 行宽/排版偏好开关 | 出 | — | 举证不足;默认排版由规格正文设计定,不做用户开关 |
| H5 | 浮动格式工具栏(1.14) | 移交 13 | — | 格式操作入口形态属编辑交互裁决 |
| H6 | 界面语言/多语言 | 出 | — | 02 决议:简体中文单语言,不做 i18n(地域假设未验前维持) |
| H7 | RTL / 竖排书写 | 出 | — | 官方标注实验性;中文 P1 无 RTL 场景 |
| H8 | emoji 单色等高级微配 | 出 | — | 高级配置文件型,反画像 |
| H9 | 状态栏(承载字数等) | 移交应用壳 | — | 09 已将字数统计形态挂它;fog 毕业后再裁 |
| H10 | 菜单栏显隐等窗口级 | 移交应用壳 | — | 窗口 chrome 属应用壳范畴 |

**规格正文承接**:外观章节 = 深浅两套观感规则 + 「默认排版设计」作为正文设计项(行宽、字体栈、标题层级观感——不设用户开关);出/延后全表入附录裁决清单。H1 的手动切换入口形态随应用壳裁决落地。
