# 03: 大纲面板

**What to build:** 侧边栏「文件 / 大纲」双 tab（宽 84px、激活加粗 + 底部 4px 色条，宽度记忆两 tab 共享）；大纲由渲染层解析文档标题生成（不改引擎）：层级缩进（每级 1em）、点击跳转（滚动定位 + 光标置入标题 + 编辑器聚焦）、滚动跟随高亮（rAF 节流）、层级折叠（箭头收起隐藏全部子级）、无标题空态占位、源码模式下禁用/空态、编辑后 300–500ms 防抖重建。

**Blocked by:** 01 (can start after)

**Status:** ready-for-agent

- [ ] 侧边栏顶部双 tab 形态（文件/大纲）、切换正常、宽度记忆共享不跳变
- [ ] 大纲正确提取 h1–h6（层级/文本/位置），每级 1em 缩进、激活项加粗
- [ ] 点击条目：滚动定位 + 光标置入标题处 + 编辑器聚焦
- [ ] 编辑区滚动时当前标题跟随高亮（rAF 节流，滚动不卡）
- [ ] 层级折叠：收起时隐藏全部子级、箭头交互正常
- [ ] 无标题文档显示空态占位；源码模式下大纲禁用/空态
- [ ] 编辑后 300–500ms 防抖重建（连续输入不抖）
- [ ] 大纲提取纯函数单测通过（doc 树 → 标题列表）
- [ ] 数千行文档下大纲刷新不卡顿
