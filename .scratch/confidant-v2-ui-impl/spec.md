# confidant UI 改造规格（仿 Typora）

> 本规格由 wayfinder 地图 effort「confidant-v2-ui」的**全部决议汇编**而成（map.md + issues/01–09，决议详情在各票 `## Answer`；视觉数值与设计规律见 [research/typora-visual-baseline.md](../confidant-v2-ui/research/typora-visual-baseline.md)；面向实施版的决议汇总见 [blueprint.md](../confidant-v2-ui/blueprint.md)）。
> 详度标尺：每项裁决有结论与依据；关键交互含边界情形；像素级实现技巧不在本文范围。
> 本文为**实施 effort 的目的地产物**：接手即以此开工，随实现推进如需修订按仓库 tracker 惯例记录变更。
>
> Status: ready-for-agent

---

## Problem Statement

confidant（知己笔记）作为 Typora 式的 WYSIWYG Markdown 桌面笔记，界面与操作方式与 Typora 气质不符：没有格式工具栏（一切操作藏进菜单）、没有主题系统（只有亮/暗两态 + 跟随系统）、没有专注/打字机模式、没有大纲面板、没有字数统计、编辑区是 60vw 自适应限宽而非纸张感、搜索是右下角浮动卡片而非 Typora 顶部条、菜单结构（八菜单含「设置」）与 Typora（七菜单含「主题」）不一致。用户希望「像 Typora 一样」的界面与操作方式；**代码框架（Electron + React + Vite 结构、引擎与包边界）不变，只改界面与操作方式**。

## Solution

confidant 的界面与操作方式全面对齐本机 Typora 42.2.0（github 主题为参照基线；布局与交互仿照、视觉为 confidant 自己的实现，不复制 Typora 主题文件）：

- **窗口骨架**：底部悬浮胶囊格式工具栏（默认隐藏、偏好设置启用、12 按钮三组、源码模式下隐藏）+ Typora 七菜单结构（文件/编辑/段落/格式/视图/主题/帮助）+ 偏好设置窗口（外观/编辑器两分类）。
- **主题系统**：github（亮，默认）/ night（暗）/ newsprint（纸感米黄）三主题，data-theme 三值整体切换，「主题」菜单勾选；取消「跟随系统」；全组件吃主题变量。
- **编辑区排版**：纸张感分级限宽（860/1024/1200px）、标题体系对齐基线（h1 2.25em 起 + bold + h1/h2 下边框）、行高保留 1.7（中文适配）、代码块 Typora 化（圆角 3px、0.9em、行号 #999、语言标签）、三主题西文字体分异（Open Sans / PT Serif，中文微软雅黑）。
- **视图模式**：专注模式（F8，非焦点段整段灰覆盖、图片淡化、不随失焦退出）、打字机模式（F9，光标行垂直居中、0.4s 过渡），两者可叠加、与源码模式互斥；视图菜单新增全屏（F11）。
- **大纲面板**：侧边栏「文件 / 大纲」双 tab，渲染层解析文档标题生成，点击跳转、滚动跟随高亮、层级折叠。
- **状态信息条**：底部页脚——右常驻字数（中文按字 + 英文按词）+ 光标段落类型、左专注/打字机按钮（hover 浮现）。
- **浮层重设计**：搜索改 Typora 顶部通栏（作用域下拉、命中琥珀 + 当前项黑底白字）；链接面板、代码块复制按钮保留交互仅主题化；横幅/对话框全部吃主题变量。

confidant 独有优势（源码模式字节直写、链接面板弹层、代码块复制按钮、40vh 滚动余量等）全部保留。

## User Stories

1. 作为 confidant 用户，我想要窗口底部悬浮的格式工具栏（加粗/斜体/删除线/标题下拉/无序列表/有序列表/任务列表/引用/代码块/表格/链接/图片），以便鼠标操作格式而不用记快捷键。
2. 作为用户，我想要工具栏**默认隐藏**、在偏好设置「外观 → 工具栏 → 显示工具栏」勾选后才显示，以便界面默认保持极简。
3. 作为用户，我想要源码模式下工具栏自动隐藏，以便不干扰全屏文本区。
4. 作为用户，我想要菜单结构对齐 Typora 七菜单（文件/编辑/段落/格式/视图/主题/帮助），以便肌肉记忆迁移。
5. 作为用户，我想要「文件 → 偏好设置…」打开偏好设置窗口（左侧分类列表 + 右侧设置区），以便集中管理设置。
6. 作为用户，我想要偏好设置「外观」分类里有「显示工具栏」开关（默认关），以便对齐 Typora 开关路径。
7. 作为用户，我想要偏好设置「编辑器」分类里有「代码块自动换行」「代码块显示行号」开关（自原「设置 → 编辑器」子菜单迁入），以便原设置不丢失。
8. 作为用户，我想要「主题」菜单列出 github/night/newsprint 三主题勾选切换、即时生效，以便选主题即选亮暗（Typora 同构）。
9. 作为用户，我想要「视图 → 外观」（跟随系统/浅色/深色）子菜单被删除、跟随系统取消，以便主题语义干净。
10. 作为用户，我想要编辑区内容宽度分级限宽（860px，≥1400px 视口 1024px、≥1800px 视口 1200px），以便宽屏也有纸张感。
11. 作为用户，我想要标题体系对齐 Typora（h1 2.25em(36px)/h2 1.75em/h3 1.5em/h4 1.25em/h5·h6 1em、bold、h1/h2 带下边框），以便正文观感是 Typora。
12. 作为用户，我想要正文行高 1.7、块间距 0.8em、引用 4px 左边框 + 灰字、表格表头/偶数行底色，以便中文阅读舒适且观感对齐。
13. 作为用户，我想要底部滚动余量保留 40vh，以便滚到文末不贴底。
14. 作为用户，我想要代码块圆角 3px、字号 0.9em、行号 #999 右对齐、新增砖红系语言标签（左上），以便代码块是 Typora 观感。
15. 作为用户，我想要 front matter 保持灰底等宽预览块但颜色随主题（#777 灰字系），以便字节行为不变且不刺眼。
16. 作为用户，我想要三主题西文字体分异（github/night 用 Open Sans、newsprint 用 PT Serif），中文仍微软雅黑体系，以便主题气质完整。
17. 作为用户，我想要专注模式（F8）：非光标所在段落整段灰覆盖（可读残影而非透明）、图片淡化、焦点段恢复正色、不随编辑器失焦退出，以便沉浸写作。
18. 作为用户，我想要打字机模式（F9）：光标行始终垂直居中、切换平滑（0.4s 过渡），以便专注写作。
19. 作为用户，我想要专注与打字机可同时开启（两勾选互不排斥）、均与源码模式互斥（置灰 + 进入源码自动退出），以便组合使用。
20. 作为用户，我想要视图菜单新增全屏（F11），以便大屏写作。
21. 作为用户，我想要侧边栏顶部「文件 / 大纲」双 tab（宽 84px、激活加粗 + 底部 4px 色条），以便快速切换导航。
22. 作为用户，我想要大纲条目按层级缩进（每级 1em）、点击跳转（滚动定位 + 光标置入标题 + 编辑器聚焦）、滚动跟随高亮、可折叠层级（收起隐藏全部子级），以便长文导航。
23. 作为用户，我想要无标题文档时大纲显示空态占位，以便不显示误导内容。
24. 作为用户，我想要源码模式下大纲禁用/空态，以便不显示错误信息。
25. 作为用户，我想要底部页脚右侧常驻显示字数统计（口径 = 中文字符数 + 英文单词数，不含空白）与光标所在段落类型（「标题 N」「代码块」「引用」等），以便随时了解文档状态。
26. 作为用户，我想要点击字数弹出明细浮层（字数/字符/段落/行数四口径）、选中口径持久化，以便按需查看口径。
27. 作为用户，我想要页脚左侧「专注模式 / 打字机」按钮（hover 浮现、激活态高亮），以便鼠标用户切换模式。
28. 作为用户，我想要搜索改为顶部通栏（约 39px 高、输入框 26px 直角透明、作用域下拉、「当前文件/整个工作区」行为不变），以便 Typora 肌肉记忆。
29. 作为用户，我想要搜索命中高亮为琥珀色、当前命中项黑底白字，以便观感对齐 Typora。
30. 作为用户，我想要「视图 → 全工作区搜索 Ctrl+Shift+F」保留、行为改为「唤起顶部条并预选『整个工作区』作用域」，以便入口不变。
31. 作为用户，我想要链接面板交互全部保留（编辑态/选区态预填、移除链接、Enter/Esc、焦点归还）、样式随主题，并可从格式工具栏「链接」按钮唤起，以便独有功能不退化。
32. 作为用户，我想要代码块复制按钮交互保留（悬停浮现、复制纯源码剥离行号、1.5s「已复制」）、样式并入主题，以便复制体验不变。
33. 作为用户，我想要横幅（文件缺失/操作通知）与输入对话框颜色随主题（三主题各自适配），以便 night 主题下不刺眼。
34. 作为用户，我想要侧边栏激活态改为「背景 + 4px 左边框」（替代整行底色），以便观感对齐 Typora。
35. 作为用户，我想要滚动条保持 Windows 系统原生，以便手感不变。
36. 作为用户，我想要主题化覆盖全组件（编辑区/侧边栏/工具栏/搜索条/浮层/偏好设置窗口/页脚），以便切换主题不残留亮色弹窗。
37. 作为用户，我想要侧边栏激活文件、双 tab 切换后宽度记忆保持一致（现状拖拽宽度持久化），以便布局不跳变。

## Implementation Decisions

1. **主题系统**：
   - `data-theme` 两值扩三值（`"github" | "night" | "newsprint"`），`:root[data-theme=…]` 三组 CSS 变量整体覆盖；**删除 `prefers-color-scheme` 跟随逻辑**；主题状态 hook 改三态并负责持久化（存储字段升级）。
   - **变量集沿用现有语义体系、按需补充**（不重构）：新增 `--blur-text`（专注淡出色）、`--tree-active-border`（侧栏激活左边框）以及工具栏/偏好设置窗口/大纲面板/状态信息条所需组件变量，命名沿用现有风格。
   - 三主题色值以票 01 基线 §1 为准（蓝图 §1 表）；**newsprint 代码高亮 token 实施时从 Typora `themes/newsprint/` 资源补提**。
   - 侧边栏激活态 = 背景 + 4px 左边框（`--tree-active-bg` + `--tree-active-border`）。
   - 滚动条保持 Windows 系统原生。
2. **菜单与窗口**：
   - 七菜单结构（文件/编辑/段落/格式/视图/主题/帮助）；「设置」顶级菜单取消，内容迁入偏好设置窗口。
   - 「文件 → 偏好设置…」打开偏好设置窗口：左侧分类列表（本次两个：外观、编辑器）、右侧设置区；分类列表预留扩展位；窗口样式吃主题变量。
   - 「主题」菜单列出三主题勾选（勾选态沿用菜单桥 setChecked 机制）。
   - 「视图」菜单扩展：源码模式（Ctrl+/）/ 专注模式（F8）/ 打字机模式（F9）/ 侧栏显示与隐藏 / 全工作区搜索 / 全屏（F11）；专注与打字机勾选互不排斥、与源码模式互斥（置灰 + 进入源码自动退出）。
   - 快捷键：已确认项按蓝图 §2.4 落地；**待实机确认项（任务列表、侧栏显隐）实施时对照 Typora 菜单对齐后落地**。
3. **格式工具栏**：
   - 底部悬浮胶囊（`bottom: 14px`、整条圆角 `18px`、按钮 `28×28` 圆角 7px、图标 13px、分隔线 1×18px、双层柔和投影），fixed 定位。
   - **默认隐藏**；仅当偏好设置「显示工具栏」开启且非源码模式时显示；无独立显隐快捷键。
   - 12 按钮分三组：加粗/斜体/删除线/标题下拉 ｜ 无序列表/有序列表/任务列表/引用/代码块/表格 ｜ 链接/图片。
4. **编辑区排版**：
   - 宽度分级：`860px` 起步，视口 ≥1400px → `1024px`、≥1800px → `1200px`；窄窗下限两侧 ≥16px 留白。
   - 标题：h1 `2.25em`/h2 `1.75em`/h3 `1.5em`/h4 `1.25em`/h5·h6 `1em`、统一 bold、**h1/h2 带 1px 下边框**（主题变量）。
   - 正文 16px、行高 1.7、块间距 0.8em、引用 4px 左边框 + 灰字、表格表头/偶数行底色；**40vh 底部滚动余量保留**。
   - 代码块：圆角 3px、字号 0.9em、行号 #999 右对齐、**语言标签**（砖红 `#b4654d` 系、吃主题变量）——⚠ 依赖引擎 codeBlock 节点 language 属性，实施时验证，拿不到则降级「仅主题化、不显示标签」。
   - front matter 预览块颜色进主题（形态不变，字节约束不碰）。
   - 字体：Open Sans（github/night）与 PT Serif（newsprint）从 Google Fonts 官方源引入打包（SIL OFL），不复制 Typora 字体资产；中文正文/UI 显式声明微软雅黑体系；代码字体链 `Consolas, 微软雅黑, monospace` 保留。
5. **视图模式**：
   - 专注模式：非光标所在段落整段文字覆盖为 `--blur-text` 色（github `#C8C8C8`/night `#686868` 系；**可读残影而非透明**；Tailwind 体系下用高优先级类替代基线 !important）；非焦点图片 opacity .2；焦点段恢复正色；**不随编辑器失焦退出**。
   - 打字机模式：内容容器 `padding-top: 50%`（光标行推至视口垂直中点）+ `0.4s padding-top 过渡`；打字机模式下底部 40vh 余量收紧为正常值（实施验证微调）。
   - 两者可叠加；与源码模式互斥。
6. **大纲面板**：
   - 渲染层解析 ProseMirror doc 树提取 heading 节点（层级/文本/位置），**不改 packages/engine**；源码模式下禁用/空态。
   - 侧边栏顶部「文件/大纲」双 tab（宽 84px、激活加粗 + 底部 4px currentColor 色条）；宽度记忆两 tab 共享；点击条目不自动收起侧边栏；不引入 pin 按钮。
   - 条目每级 1em 缩进、字号随侧边栏 14px、激活项加粗（700）；点击 = 滚动定位 + 光标置入标题处 + 编辑器聚焦；滚动跟随高亮（rAF 节流）；doc 变化 300–500ms 防抖重建；层级折叠（箭头收起隐藏全部子级）；无标题空态占位（opacity .6）。
7. **状态信息条**：
   - 底部 28–30px 页脚：左「专注模式/打字机」按钮（hover 浮现、激活态 `#1868AD`）、右字数常驻 + 光标段落类型；border-top 1px 吃主题变量。
   - 字数口径：**中文字符数 + 英文单词数**（不含空白）；点击弹四口径明细（字数/字符/段落/行数），选中口径持久化。
   - 渲染层从 ProseMirror doc 遍历统计（不改引擎）；输入停顿 200–300ms 防抖；光标段落类型实时跟随 selection（heading→「标题 N」、codeBlock→「代码块」、blockquote→「引用」、list→「列表」等）。
8. **搜索顶部条**：
   - 顶部通栏（约 39px 高、输入框 26px 直角透明 12px、吃主题变量）；作用域「当前文件/整个工作区」双胶囊改为 76px 下拉；Enter 下一个 / Shift+Enter 上一个 / Esc 关闭并清除高亮（行为保留）；命中高亮**琥珀 `rgba(248,192,116,.3)` + 当前项黑底白字**；「视图 → 全工作区搜索 Ctrl+Shift+F」行为改为「唤起顶部条 + 预选『整个工作区』」；**替换模式不引入**。
9. **浮层主题化**：链接面板、代码块复制按钮、横幅（DocMissingBanner/ChangeNoticeToast）、输入对话框全部并入主题变量（形态与交互不变；Toast 深色底改用主题变量表达）。

## Testing Decisions

- **原则**：只测外部行为、不测实现细节（不断言 CSS 变量值本身）；纯逻辑走单测，真实观感走对照清单 + 截图。
- **主 seam（渲染层纯逻辑单测）**：把可自动验证的行为抽为纯函数/hook，沿用「与源文件同目录 `.test.ts`」惯例。覆盖：大纲标题提取（doc 树 → 标题列表）、字数统计（中文按字 + 英文按词）与光标段落类型映射、主题状态机（三态切换 + 持久化）、菜单模板结构与点亮/置灰逻辑、视图模式状态（专注/打字机互不排斥、与源码互斥）。
- **引擎回归矩阵**：本次不改 packages/engine——现有矩阵（front matter 字节原样、源文除明确规范化外不改写、无静默丢内容）跑绿即守线，不新增引擎测试。
- **smoke/E2E 探针扩展（必执行）**：现有自检机制加断言——`data-theme` 三值切换断言、专注/打字机类名存在断言、字数统计渲染断言、**三主题各截一屏存档**（供对照评审）。
- **对照验收清单（人工终验，必执行）**：蓝图附录 A 逐项与 Typora 42.2.0 并排比对（A1 新增 9 项 / A2 对齐 10 项 / A3 独有保留 10 项）。
- **先例**：packages/engine 的 normalization-matrix/roundtrip/frontmatter 矩阵测试；渲染层 editor/ 下纯逻辑测试（同目录 `.test.ts` 惯例）。

## Out of Scope

- 新 Markdown 语法能力（数学公式、图表/mermaid、脚注、TOC 等）——属功能扩充，留 confidant-v2 功能裁决。
