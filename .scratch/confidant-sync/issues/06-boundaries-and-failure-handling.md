# 06: 边界与失败处理

**What to build:** 无法安全处理的条目被**跳过并列出来**，计入「未完成」而不是算作成功——用户能看到「498 / 500 已同步，2 个跳过（文件名含非法字符）」。涵盖：超过大小上限的文件、符号链接（不跟随）、文件名含 Windows 非法字符、大小写冲突、超长路径、未知条目类型。

失败处理：单个文件传输失败重试 2 次（指数退避）后跳过，**不影响其他文件**；用户名或密码错误立刻停下并提示，不反复重试（避免触发服务端登录失败锁定）；整体失败给出错误摘要与「重试」入口，错误信息遮蔽密码。中断：同步未完成时关窗弹一次确认，确认后取消、落盘、正常关窗（**不阻止关窗**）；切换工作区时当前同步被干净取消。日志写入本机滚动文件，不含密码。

规格依据：决议 17–19、41–43、58–62、64。
