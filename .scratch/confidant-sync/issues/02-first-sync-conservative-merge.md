# 02: 首次同步——保守合并，带进度与取消

**What to build:** 用户点「同步」发起一次同步，应用扫描工作区与远端根，把两侧内容互相补齐：本地有远端没有的上传，远端有本地没有的下载，同名同内容视为已同步。**一个字都不删。** 页脚状态条实时显示「同步中 123 / 540」并可点取消；结束后显示「上传 3 / 下载 2」这样的摘要。同步状态表按工作区落地，记住每个文件这次的**基准版本**。同步前强制 flush 待保存内容，同步期间允许继续编辑。

规格依据：决议 6–19、29–34、50–55。

**Blocked by:** [01a](01a-sync-package-and-webdav-client.md), [01b](01b-credentials-ipc-and-settings-dialog.md)（原票 01 已拆为这两张，见 [00-split-note.md](00-split-note.md)）

**Status:** ready-for-agent

- [ ] 点「同步」发起一次同步；进行中按钮禁用，不做重入
- [ ] 本地有、远端无的文件被上传
- [ ] 远端有、本地无的文件被下载（含子目录，逐级创建）
- [ ] 同名同内容的文件不重复传输
- [ ] **首次同步不删除任何文件**——两侧各放一份只在单侧存在的文件，同步后两份都还在
- [ ] 远端缺失的目录被逐级创建；对已存在的目录不报错
- [ ] 上传后回读校验大小，不一致计为未完成
- [ ] 页脚显示「同步中 已完成 / 总数」；结束后显示上传与下载计数
- [ ] 取消能在同步中途停下，已完成的部分保留
- [ ] 同步前强制 flush 未保存内容；同步中可继续编辑，不锁定编辑区
- [ ] 同步是字节级搬运：远端文件原样下载、本地文件原样上传，不经过编辑引擎
- [ ] 同步写本地文件走仓库现有的外部变更通道，且**不注册**自身操作回声抑制
- [ ] 同步状态表按工作区落在本机状态文件，记录每个文件的基准内容 hash、远端验证符、修改时间与大小
- [ ] 状态表**每完成一个文件写一次**，不是单个事务
- [ ] 状态表读取失败 → 退化为「无状态表」→ 保守合并，**绝不静默重建为空表**
- [ ] 锁文件阻止两个应用实例同时同步同一工作区
- [ ] 多个工作区的同步任务串行执行，一次一个
- [ ] 请求串行，并发数为 1
- [ ] 自动排除所有点开头条目与 `Thumbs.db` / `desktop.ini`；排除规则在做同步设置界面写明
- [ ] 单测走真实临时目录 + 内存假服务端，覆盖：单侧新增上传 / 单侧新增下载 / 同名同内容 / 空工作区 / 空远端
- [ ] `npm run typecheck` 与 `npm test` 全绿
