# 08: 真机验收——绿联 NAS

**What to build:** 在真实绿联 NAS 上按一条竖切跑通全流程：配置 → 测试连接 → 首次保守合并（含远端非空）→ 单侧改动 → 双向同步 → 制造冲突 → 双向删除。把结果、失败与「待验证清单」的更新写进本票。

脚本形态复用仓库现有的自检/冒烟模式（环境变量驱动、成功时退出码 0）。**注意仓库既有约定：每次运行须用全新目录或重建夹具**，否则残留导致断言错位。

规格依据：决议 65–68，以及规格 Further Notes 的「待验证清单」。

**Blocked by:** 04, 05, 06, 07

**Status:** ready-for-agent

- [ ] 环境变量驱动的真机脚本落地，复用仓库现有自检/冒烟模式
- [ ] 每次运行使用全新夹具目录或先重建夹具
- [ ] 竖切覆盖：配置连接 → 测试连接 → 首次保守合并（远端非空）→ 单侧改动双向同步 → 冲突 → 双向删除
