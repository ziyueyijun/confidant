# 01: 连接配置与测试连接

**What to build:** 用户能在主窗口菜单「文件 → 同步设置…」打开一个**工作区级**的同步设置对话框，填入 WebDAV 地址、用户名与密码，点「测试连接」后得到明确结果（可达 / 认证失败 / 目录不存在）。远端目录非空时弹一次说明：首次同步会执行保守合并，**不会删除任何文件**。对话框内可见「远端以明文存储，请确认你信任该服务器」；地址为 `http` 时出现密码明文过网的警告；「信任此服务器的证书」开关默认关闭、开启时警告；工作区落在常见网盘同步目录内时给一次提示（只提示，不阻止）。凭据加密保存，重启后无需重输；解密失败时提示重新输入。工作区被移动或改名后，对话框显示「未找到该工作区」。

这一票同时立起**同步功能包**、**自研的薄 WebDAV 客户端**（六个动词 + 路径编码与 href 归一化 + Basic 认证）与**内存版假 WebDAV 服务端**——后续每一票都长在这三样上面。

规格依据：决议 1–5、38–52、56–57。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 「文件 → 同步设置…」为**当前工作区**打开对话框；未打开工作区时给出明确提示
- [ ] 填入地址、用户名、密码 → 「测试连接」区分「可达」「认证失败」「目录不存在」三种结果
- [ ] 远端目录非空时给出说明，文案明确写出「不会删除任何文件」
- [ ] 「远端以明文存储，请确认你信任该服务器」在对话框内可见
- [ ] 地址为 `http` 时出现密码明文过网的警告；改为 `https` 后警告消失
- [ ] 「信任此服务器的证书」默认关闭；开启时出现警告
- [ ] 工作区位于常见网盘同步目录内时出现一次提示；检测只用于提示，不参与任何自动决定
- [ ] 密码经 `safeStorage` 加密后写入本机状态文件，重启应用后无需重输
- [ ] 凭据解密失败（换机器、换 Windows 账户）时提示重新输入，不静默失败
- [ ] 工作区被移动或改名后，对话框显示「未找到该工作区」
- [ ] 同步配置按工作区存放，不写进工作区，不写进远端
- [ ] 自研 WebDAV 客户端实现列目录 / 下载 / 上传 / 删除 / 建目录 / 移动六个动词
- [ ] 路径编码与 href 归一化有单测覆盖：中文、空格、`#`、`%`、非 ASCII 目录名
- [ ] 列目录只用深度 1；建目录逐级创建，**400 与 405 都当作「已存在」**
- [ ] 内存版假服务端可应答六个动词，并能模拟畸形响应：多级建目录返 405、对已存在集合返 400、不返回验证符、文件名含 XML 实体（`&`、`<`）、列举返回空
- [ ] 新建的功能包通过 `npm run lint:boundaries`；`npm run typecheck` 与 `npm test` 全绿
