# 07: 启动探测与收尾提示

**What to build:** 启动应用后做**一次只读**的远端探测。若远端存在本机状态表里没有的变更，页脚状态条出现一个小圆点，提示用户该同步了。同一票补上同步循环的收尾比对：同步期间若有文件又被改动，结束时状态条提示「还有 N 个文件的改动未同步」，**不自动重跑**。

规格依据：决议 8、11。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 启动后对远端根做一次只读探测；存在本机未知变更时页脚出现小圆点
- [ ] 无变更时不显示圆点
- [ ] 同步完成后圆点消失
- [ ] 探测失败（离线、认证失败、目录不可达）不打断启动，静默降级为不显示
- [ ] **不做轮询**，不做定时探测，不自动同步
- [ ] 同步期间被再次改动的文件在结束时被统计，状态条提示「还有 N 个文件的改动未同步」
- [ ] **不自动重跑**（用户持续输入时不得形成循环）
- [ ] 未打开工作区、或该工作区未配置同步时不发起任何网络请求
- [ ] 单测覆盖：有变更 / 无变更 / 探测失败 / 收尾比对检出 N 个变化
- [ ] `npm test` 与 `npm run typecheck` 全绿
