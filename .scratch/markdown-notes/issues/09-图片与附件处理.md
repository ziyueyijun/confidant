# 图片与附件处理

Type: grilling
Status: open
Blocked by: —

## Question

截图粘进来之后发生什么？

已定：存库根 `attachments/`，链接用相对路径。剩下的细节：

1. **命名**：粘贴进来的图片文件叫什么？时间戳、哈希、还是「笔记名-序号」？要避免不同笔记的图片撞名，也要让人在文件管理器里能认出来。
2. **来源差异**：剪贴板位图（截图工具）、剪贴板里的图片文件、从浏览器拖进来的图片（是 URL 不是二进制）、从资源管理器拖进来的本地文件。四种来源行为分别是什么？拖进来的本地文件是复制还是引用原位置？
3. **网络图片**：markdown 里写了 `![](https://...)`，要不要下载到本地？要不要显示远程图？（离线可用 vs 隐私：加载远程图会暴露 IP）
4. **孤儿附件**：删掉笔记时，它引用的图片怎么办？删掉引用某图的那一行时呢？自动清理有误删风险（同一张图可能被多篇引用），不清理会攒垃圾。**倾向：不自动删，提供手动「找出未被引用的附件」**，但要确认。
5. **显示**：图片在编辑器里的默认尺寸与最大宽度；超大图怎么办；加载失败长什么样；要不要支持点击放大。
6. **可移植性验证**：把整个库文件夹拷到另一台机器 / 用 Typora 打开，图片还能显示吗？相对路径的基准是笔记所在目录还是库根——这两者在子文件夹里的笔记上会得出不同的路径，必须明确。
7. **非图片附件**（pdf、docx）算不算 MVP？倾向划出去。
