# 选定编辑器内核

Type: grilling
Status: open
Blocked by: 01, 02

## Question

用哪个编辑器内核实现 Typora 式 inline WYSIWYG？

带着调研事实和「最小 diff」的结论，做出选型决定并写清理由与被放弃的选项。

**验收标准**（按优先级，任一不满足即淘汰）：

1. 中文 IME 稳定性：组合输入不吞字、候选框不跳位、光标不错位。
2. 磁盘纯净度 / round-trip 行为符合「最小 diff 保真要不要当硬需求」的结论。
3. 能表达 CommonMark + 表格 + 任务列表的 inline 渲染，含代码块内部纯文本编辑。
4. 单文件万字长文不卡。
5. 许可证允许自用。
6. 维护活跃，文档与社区足够支撑一个人长期维护。

**输出**：选定的内核 + 版本、被淘汰选项及淘汰原因、已知需要自己填的坑清单（这些坑可能graduate成新 ticket）。

这是不可逆决定，reverse 成本是重写编辑层，值得写一份 ADR。
