# 界面布局原型

Type: prototype
Status: open
Blocked by: —

## Question

这个软件长什么样？

做一个可点的静态原型（不接真实编辑器内核，纯布局与视觉），让用户反应。要覆盖：

- **主布局**：侧边栏（文件树）+ 标签页 + 编辑区的比例与位置；侧边栏能否折叠；编辑区是否有最大宽度（居中排版 vs 满宽）。
- **文件树**：文件夹层级的呈现、当前文件高亮、排序方式、新建/重命名的入口。
- **标签页**：样式、溢出怎么办、有未保存改动时的标识（虽然是自动保存）。
- **搜索**：是侧边栏面板、顶部浮层，还是独立视图？Ctrl+P 快速跳转和全文搜索是同一个入口还是两个？
- **编辑区排版**：正文字体与字号、行高、标题层级的视觉比例、代码块样式、引用块样式、中英混排的字体搭配。
- **暗色主题**：暗色与亮色各一版。
- **Frontmatter 的呈现**：原样保留的 YAML 块在编辑器顶部长什么样。

**输出**：原型链接为 asset + 用户确认的布局与视觉方向。这张 ticket 不依赖内核选型，可以立刻开工。
