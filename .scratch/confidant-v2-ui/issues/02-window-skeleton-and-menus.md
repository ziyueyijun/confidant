## Answer

（2026-09-07，与用户对话决议；四问四答，Q14 为定制、Q15-18 按推荐。）

1. **格式工具栏**：Typora 形态——**底部悬浮胶囊工具栏**（bottom 14px、圆角 18px、28×28 按钮，视觉基线见票 01）。**默认隐藏**，必须在「**偏好设置窗口 → 外观 → 工具栏 → 显示工具栏**」勾选后才显示（2026-09-07 用户实机确认 Typora 开关位置即「文件 → 偏好设置 → 外观 → 工具栏 → 显示工具栏」）。启用后：12 个常用按钮分三组——加粗/斜体/删除线/标题下拉｜无序列表/有序列表/任务列表/引用/代码块/表格｜链接/图片。视图菜单**不**设第二开关（单一状态源，避免双勾选不同步）。启用状态下**无独立显隐快捷键**——工具栏显隐仅由偏好设置勾选控制（原「F9 切换工具栏」推断已被实机确认推翻：F9 实为打字机模式，见票 05 Answer；toggleToolbar 上下文属 asar 压缩碎片误读）。
2. **菜单结构**：对齐 Typora 七菜单——文件/编辑/段落/格式/视图/主题/帮助。「文件」菜单加「偏好设置…」入口（Typora 同款），打开偏好设置窗口（规格见第 5 条）；原「设置 → 编辑器」子菜单取消，内容并入偏好设置窗口。「主题」菜单占位，内容由票 03-theme-system 决议。**修正注记（2026-09-07）**：用户实机确认 Typora 开关路径「文件 → 偏好设置 → 外观 → 工具栏 → 显示工具栏」，据此**推翻**此前「不做独立设置窗口」裁定——confidant 需要 Typora 式偏好设置窗口；map 雾区「设置界面形态」已裁决，不补票。
3. **快捷键**：以 Typora 为准对齐冲突项；confidant 独有功能（如 Ctrl+Shift+F 全工作区搜索）保留原键。已确认（2026-09-07 用户实机读 Typora 视图菜单）：**专注模式 F8**、**打字机模式 F9**、源码模式 Ctrl+/（与 confidant 现状一致）、全屏 **F11**。⚠ **修正**：此前 asar 碎片推断「F8=打字机、F9=工具栏开关」作废。仍待实机确认后落实施：任务列表（confidant Ctrl+Shift+9 vs Typora 疑似 Ctrl+Shift+M）、侧栏显隐（confidant Ctrl+Shift+B vs Typora 疑似 Ctrl+Shift+L）。
4. **源码模式互斥**：进入源码模式（Ctrl+/）时底部工具栏隐藏（不显示），退出后恢复。

5. **偏好设置窗口**（修正注记后新增裁定）：Typora 式独立窗口——「文件 → 偏好设置…」打开（快捷键待与 Typora 对齐，Typora 为 Ctrl+逗号，⚠ 未实机确认）。窗口布局：左侧分类列表、右侧设置区。本次范围两个分类：
   - **外观**：「显示工具栏」勾选（默认关，即格式工具栏的启用开关）。
   - **编辑器**：「代码块自动换行」「代码块显示行号」勾选（自原「设置 → 编辑器」子菜单迁入）。
   分类列表预留扩展位（快捷键、导出等暂不实现）。窗口外观并入主题体系（视觉参数由票 03/04 决议驱动）。
