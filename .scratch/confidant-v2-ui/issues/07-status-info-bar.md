## Answer

（2026-09-07，与用户对话决议；Q39-Q42 全部按推荐。基线依据：票 01 基线 §3.1（页脚）与 §4.3（字数统计）。）

1. **形态与内容**：仿 Typora 页脚完整版——底部 28–30px 信息条：左「专注模式 / 打字机」切换按钮（hover 浮现）、右「字数统计 + 光标段落类型」。专注/打字机入口三处并存：视图菜单勾选、快捷键（F8/F9，票 05 决议）、页脚按钮（鼠标用户补充入口；按钮激活态 `#1868AD` 基线）。
2. **字数口径**：默认「字数」= **中文字符数 + 英文单词数**（不含空白）；点击字数弹出明细浮层（字数/字符/段落/行数四口径，基线表格形态 §4.3），选中的口径**持久化到设置**。
3. **数据来源与性能**：渲染层从 ProseMirror doc 遍历统计（不动 packages/engine）；输入停顿 **200–300ms 防抖**刷新；光标段落类型**实时跟随** selection（向上找块节点：heading→「标题 N」、codeBlock→「代码块」、blockquote→「引用」、list→「列表」等）。
4. **视觉**：字数**常驻显示**（12px、opacity .75、点击态背景 #eee，基线 §4.3）；模式按钮 hover 浮现（基线隐藏式 UI 规律 6）；信息条 border-top 1px（主题变量）。
