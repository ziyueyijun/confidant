## Question

**视图模式**的决议：新增专注模式（非光标所在段落淡出）与打字机模式（光标行始终垂直居中），行为对齐 Typora，定到可实施的程度。

已定方向（map Notes）：专注 + 打字机都做；入口放视图菜单；快捷键查证 Typora 后对齐（Typora 的专注/打字机快捷键需确认——可查官方文档或资源）。

待决议：

1. **专注模式行为规格**：进入/退出方式（菜单 + 快捷键）、非焦点段落淡出到什么程度、光标离开编辑区时（点侧边栏/工具栏）的行为、与源码模式的互斥（源码模式下禁用？）。
2. **打字机模式行为规格**：光标行垂直居中的实现（滚动跟随算法）、输入/点击/方向键移动时光标行保持居中、与专注模式能否叠加。
3. **实现约束**：两者都作用于 TipTap/ProseMirror 编辑器容器（滚动 + CSS），需要确认渲染层 `editor-scroll` 的滚动结构能否支撑；若需引擎配合（如提供光标行位置），记录接口需求。
4. **视图菜单结构**：现有「视图」菜单如何扩展（源码模式/侧栏/全工作区搜索/外观 已占位）。

产出：视图模式规格（两者行为规格、快捷键、互斥关系、实现约束与接口需求），记录于本票 Answer。

## Answer

（2026-09-07，与用户对话决议；Q31 实机事实、Q32/Q33 按推荐。）

1. **快捷键事实（Q31，用户实机读 Typora 视图菜单）**：专注模式 **F8**、打字机模式 **F9**、源码模式 **Ctrl+/**（与 confidant 现状一致，无冲突）。**修正**：票 02 此前 asar 碎片推断「F8=打字机、F9=工具栏开关」作废（已同步修正票 02 Answer）；工具栏显隐仅由偏好设置勾选控制，无独立快捷键。
2. **专注模式（Q32）**：非光标所在段落整段文字覆盖为 `--blur-text` 色（github `#C8C8C8`/night `#686868`——**可读残影而非透明**，基线 §5.1 机制；confidant 的 Tailwind 体系下用高优先级类替代 !important）；非焦点图片 opacity .2；光标所在段落恢复正色；**模式不随编辑器失焦退出**（点侧边栏/工具栏保持淡出态）。入口：视图菜单「专注模式」勾选项 + 快捷键 **F8**。与源码模式互斥（源码模式下置灰，进入源码模式自动退出）。
3. **打字机模式（Q33）**：内容容器 `padding-top: 50%`（光标行推至视口垂直中点）+ `0.4s padding-top 过渡`（基线 §5.2 机制平移到 confidant 的 editor-scroll 内容容器）；输入/点击/方向键移动时光标行由 padding 机制自然保持居中；**与专注模式可同时开启**（两个菜单勾选互不排斥）；打字机模式下底部 40vh 滚动余量收紧为正常值（避免双倍滚动空间，文末光标仍能居中——实施细节，由实施票验证微调）。入口：视图菜单「打字机模式」勾选项 + 快捷键 **F9**。与源码模式互斥（同上）。
4. **视图菜单扩展**：源码模式（Ctrl+/）/ 专注模式（F8）/ 打字机模式（F9）/ 侧栏显示与隐藏（Ctrl+Shift+B）/ 全工作区搜索（Ctrl+Shift+F）/ 全屏（F11，新增自票 02）。专注与打字机勾选态、源码模式互斥置灰规则由 menu-bridge 点亮逻辑维护。
