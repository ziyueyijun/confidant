## Question

**自有浮层重设计**的决议：confidant 自有的三个交互浮层——搜索面板（Ctrl+F 右下浮动卡片）、链接面板（顶部居中弹层）、代码块复制按钮（悬停浮现）——如何 Typora 化，定到可实施的程度。

已定方向（map Notes）：搜索改成 Typora 式顶部搜索条；链接面板保留弹层但主题化；代码块复制按钮保留但样式并入主题。

待决议：

1. **搜索顶部条**：形态（顶部居中横条）、与现有功能的对齐（当前文件/整个工作区两种作用域如何保留？Enter/Shift+Enter 上下、Esc 关闭、命中高亮不落盘等现有行为是否原样搬入顶部条）、与「视图 → 全工作区搜索 Ctrl+Shift+F」的入口关系。
2. **链接面板**：现有弹层交互（编辑态/选区态预填、移除链接按钮）保留，样式并入主题；是否因顶部工具栏的出现改变唤起方式（工具栏「链接」按钮）。
3. **代码块复制按钮**：保留悬停浮现，样式并入主题体系；与票 04-editor-typography 的分工（本票定交互与按钮形态，04 定代码块整体视觉）。
4. **其他浮层**：横幅（文件缺失/操作通知）与输入对话框是否一并主题化（既定方向外的小决策，一并裁定）。

产出：浮层重设计规格（搜索顶部条交互、链接面板与复制按钮的形态、横幅/对话框主题化范围），记录于本票 Answer。

## Answer

（2026-09-07，与用户对话决议；Q43-Q46 全部按推荐。基线依据：票 01 基线 §4.2（搜索条）与 §4.5（浮层）。）

1. **搜索顶部条**：Typora 式**顶部通栏**（fixed 顶部、约 39px 高、输入框 26px 直角透明、12px 字号、吃主题变量）；作用域「当前文件 / 整个工作区」双胶囊改为 Typora 式**下拉**（76px）；现有行为全保留——当前文件走引擎 findInDoc 实时匹配、工作区 180ms 防抖主进程搜索、Enter 下一个 / Shift+Enter 上一个 / Esc 关闭并清除高亮；命中高亮换基线观感——**临时琥珀 `rgba(248,192,116,.3)` + 当前项黑底白字**（替代现黄色系）；「视图 → 全工作区搜索 Ctrl+Shift+F」保留，行为改为「唤起顶部条 + 预选『整个工作区』作用域」；**替换（replace）模式不引入**（新功能非界面改造，留 v2 功能裁决）。
2. **链接面板**：保留现有交互全部细节（编辑态/选区态预填、移除链接按钮、Enter 提交/Esc 关闭、焦点归还编辑器），样式并入主题；唤起方式 Ctrl+K 不变，另接入格式工具栏第三组「链接」按钮。
3. **代码块复制按钮**：保留悬停浮现交互（复制纯源码剥离行号、1.5s「已复制」反馈），样式并入代码块整体视觉（与票 04 分工：04 定视觉含按钮形态、本票定交互逻辑）。
4. **横幅与对话框**：DocMissingBanner、ChangeNoticeToast、TextPrompt 全部并入主题变量（形态与交互不变，三主题各自适配；Toast 深色底改用主题变量表达）——补全票 03 Q24「全组件吃主题变量」的遗漏清单。
