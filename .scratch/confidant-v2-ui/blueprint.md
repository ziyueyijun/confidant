# 仿 Typora 界面改造蓝图（confidant-v2-ui）

> 本蓝图是 wayfinder 地图「仿 Typora 界面改造」的目的地本体：汇整票 01–08 的全部决议，供实施直接驱动。决策依据见各票 Answer（链接附在各节）；视觉数值实读自本机 Typora 42.2.0（基线文档 `.scratch/confidant-v2-ui/research/typora-visual-baseline.md`）。
> 日期：2026-09-07。状态：待用户评审（评审意见并入后定稿）。

---

## 1. 视觉方向总述

- **仿「布局与交互」，不复制 Typora 主题文件**（商业软件版权边界）：配色/字体/主题均为 confidant 自己的实现，只借鉴设计语言与数值。
- 参照基线 = Typora 42.2.0 **github 主题**（用户默认观感）。
- 从基线提炼的 5 条最核心设计规律（实施时贯穿所有组件）：
  1. **层级差用灰阶不用色相**：侧边栏/控件比正文灰一档，强调色只留给链接、选区、激活态（低饱和蓝系）。
  2. **圆角规律**：默认直角，小件 2–4px，唯一大圆角是底部悬浮工具栏胶囊（18px）。
  3. **间距节奏 24px 系**：块间距、标题下距锚定 24px 节奏；正文行高 1.5–1.6（confidant 中文适配 1.7）。
  4. **隐藏式 UI**：页脚按钮、侧栏按钮 hover 才显示，常态只有内容。
  5. **激活态「4px 左边框 + 背景」**：比整行变色克制。

### 三主题核心色值（基线 §1，完整表见基线文档）

## 2. 窗口骨架与菜单（票 02-window-skeleton-and-menus）

### 2.1 格式工具栏

- **现状**：无工具栏，一切操作走菜单与快捷键。
- **目标**：Typora 形态——**底部悬浮胶囊工具栏**（`bottom: 14px`、整条圆角 `18px`、按钮 `28×28` 圆角 7px、图标 13px、分组分隔线 1×18px、双层柔和投影）。
- **默认隐藏**，必须在「**偏好设置窗口 → 外观 → 工具栏 → 显示工具栏**」勾选后才显示（用户实机确认 Typora 开关位置即「文件 → 偏好设置 → 外观 → 工具栏 → 显示工具栏」）。**无独立显隐快捷键**（原 F9 推断已作废，见票 05 修正）。
- 启用后 12 按钮分三组：**加粗 / 斜体 / 删除线 / 标题下拉** ｜ **无序列表 / 有序列表 / 任务列表 / 引用 / 代码块 / 表格** ｜ **链接 / 图片**。
- **源码模式下自动隐藏**（进入 Ctrl+/ 后工具栏不显示，退出恢复）。
- 视图菜单不设第二开关（单一状态源，避免双勾选不同步）。

### 2.2 菜单结构

- **现状**：文件/编辑/段落/格式/视图/**设置**/帮助（八菜单，「设置 → 编辑器」子菜单承载代码块两勾选）。
- **目标**：对齐 Typora 七菜单——**文件/编辑/段落/格式/视图/主题/帮助**：
  - 「文件」新增「偏好设置…」（打开偏好设置窗口，见 2.3）；原「设置 → 编辑器」子菜单取消，内容迁入偏好设置窗口。
  - 「主题」菜单占位（内容见 §3，三主题勾选切换）。
  - 「视图」扩展：源码模式（Ctrl+/）/ 专注模式（F8）/ 打字机模式（F9）/ 侧栏显示与隐藏（Ctrl+Shift+B）/ 全工作区搜索（Ctrl+Shift+F）/ **全屏（F11，新增）**。

### 2.3 偏好设置窗口（新）

- Typora 式独立窗口：「文件 → 偏好设置…」打开；左侧分类列表、右侧设置区。
- 本次范围两个分类：
  - **外观**：「显示工具栏」勾选（默认关）。
  - **编辑器**：「代码块自动换行」「代码块显示行号」勾选（自原设置子菜单迁入）。
- 分类列表预留扩展位（快捷键、导出等暂不实现）。窗口外观并入主题体系。

### 2.4 快捷键映射（已确认 vs 待确认）

| 功能 | confidant 现状 | 决议 |
|---|---|---|
| 源码模式 | Ctrl+/ | ✅ 与 Typora 一致，保留 |
| 专注模式 | 无 | ✅ 新增 **F8**（实机确认） |
| 打字机模式 | 无 | ✅ 新增 **F9**（实机确认） |
| 全屏 | 无 | ✅ 新增 **F11** |
| 任务列表 | Ctrl+Shift+9 | ⚠ Typora 疑似 Ctrl+Shift+M，待实机确认后对齐 |
| 侧栏显隐 | Ctrl+Shift+B | ⚠ Typora 疑似 Ctrl+Shift+L，待实机确认后对齐 |
| 其余（标题 Ctrl+1-6、引用/代码块/表格/链接/图片、Ctrl+F、Ctrl+O/S/Z/Y 等） | 与 Typora 一致 | ✅ 保留 |
| 全工作区搜索 Ctrl+Shift+F 等 confidant 独有 | — | ✅ 保留原键 |

## 3. 主题系统（票 03-theme-system）

- **现状**：亮/暗两态（data-theme + prefers-color-scheme 跟随系统），「视图 → 外观」子菜单三态。
- **目标**：
  - **取消「跟随系统」**：「视图 → 外观」子菜单删除，`prefers-color-scheme` 逻辑删除；「主题」菜单直接列三主题勾选切换（Typora 同构——选主题即选亮暗）。
  - `data-theme` 两值扩三值：`"github" | "night" | "newsprint"`，`:root[data-theme=…]` 三组 CSS 变量整体覆盖；勾选态沿用 menu-bridge setChecked；use-app-theme 改三态并持久化（存储字段升级）。
  - **变量集沿用现有语义体系、按需补充**（不重构）：新增 `--blur-text`（专注淡出色）、`--tree-active-border`（侧栏激活左边框）、工具栏/偏好设置窗口/大纲/状态条组件所需变量。
- **主题化边界（全组件吃变量）**：编辑区全文、代码块与代码高亮（每主题一组 token）、侧边栏（含文件/大纲双 tab）、格式工具栏、搜索顶部条、链接面板、横幅/通知/对话框、偏好设置窗口、状态信息条。**滚动条保持 Windows 系统原生**。
- **侧边栏激活态**：改为基线规律 5——背景 + **4px 左边框**（`--tree-active-bg` + `--tree-active-border`），替代现整行底色。
- ⚠ **newsprint 代码高亮 token 基线未提取**（night 有独立暗色语法文件），实施时从 `themes/newsprint/` 资源补提。

## 4. 编辑区排版（票 04-editor-typography）

- **内容宽度**：60vw 自适应 → **分级限宽**：`860px` 起步，视口 ≥1400px → `1024px`、≥1800px → `1200px`；窄窗下限保留两侧 ≥16px 留白。
- **标题体系**：对齐基线——h1 `2.25em`(36px)/h2 `1.75em`(28px)/h3 `1.5em`(24px)/h4 `1.25em`/h5·h6 `1em`；统一 bold；**h1/h2 带 1px 下边框**（主题变量）。
- **正文与块级**：正文 16px；**行高保留 1.7**（中文适配）；块间距 0.6em → 0.8em；引用 **4px 左边框 + 灰字**（#777 系主题变量）；表格对齐基线（表头底 + 偶数行底）；**底部滚动余量保留 40vh**（为打字机模式留足滚动空间）。
- **front matter 块**：保持灰底等宽预览块形态（§4.3 字节保留约束不动），颜色吃主题变量（#777 灰字系）；折叠交互不做（雾区候选增强）。
- **代码块视觉**：圆角 6px → **3px**；字号 0.9em；行号 `#999` 右对齐；**新增语言标签**（左上、砖红 `#b4654d` 系、吃主题变量）——⚠ 依赖引擎 codeBlock 节点 language 属性，实施时验证，拿不到则降级「仅主题化不显示标签」；代码块自动换行/行号两个设置项保留。
- **字体策略**：三主题西文字体分异——github/night 无衬线（**Open Sans**，SIL OFL）、newsprint 衬线（**PT Serif**，SIL OFL），从 Google Fonts 官方源引入打包（不复制 Typora 字体资产）；**中文显式声明微软雅黑体系**；代码字体链 `Consolas, 微软雅黑, monospace` 保留。

## 5. 视图模式（票 05-focus-and-typewriter-modes）

- **快捷键（实机确认）**：专注模式 **F8**、打字机模式 **F9**、源码模式 **Ctrl+/**（与现状一致）。修正：asar 碎片推断「F8=打字机、F9=工具栏开关」作废。
- **专注模式**：非光标所在段落整段文字覆盖为 `--blur-text` 色（github `#C8C8C8`/night `#686868`——**可读残影而非透明**；Tailwind 体系用高优先级类替代 !important）；非焦点图片 opacity .2；焦点段恢复正色；**不随编辑器失焦退出**。入口：视图菜单勾选 + F8。
- **打字机模式**：内容容器 `padding-top: 50%`（光标行推至视口垂直中点）+ `0.4s padding-top 过渡`（基线 §5.2 机制平移到 editor-scroll 内容容器）；光标行由 padding 机制自然保持居中；打字机模式下底部 40vh 余量收紧为正常值（实施微调验证）。入口：视图菜单勾选 + F9。
- **两模式可叠加**；均与源码模式互斥（源码模式下置灰，进入源码自动退出）。

## 6. 大纲面板（票 06-outline-panel）

- **数据来源**：渲染层直接解析 ProseMirror doc 树（heading 节点：层级/文本/位置），**不改 packages/engine**；**源码模式下大纲禁用/空态**。
- **交互**：条目每级 1em 缩进（h1 顶格）；字号随侧边栏 14px；激活项加粗（700）；点击 = 滚动定位 + 光标置入标题处 + 编辑器聚焦；滚动跟随高亮（rAF 节流计算视口顶部当前标题）；doc 变化 **300–500ms 防抖重建**；**层级折叠**（箭头收起隐藏全部子级）；无标题文档空态占位（opacity .6）。无需虚拟化。
- **与文件树共存**：侧边栏顶部「文件 / 大纲」双 tab（宽 84px、激活加粗 + 底部 4px currentColor 色条，基线实测）；宽度记忆两 tab 共享；点击条目不自动收起侧边栏；不引入 pin 按钮（Ctrl+Shift+B 已覆盖显隐）。

## 7. 状态信息条（票 07-status-info-bar）

- **形态**：仿 Typora 页脚完整版——底部 28–30px 信息条：左「专注模式 / 打字机」切换按钮（hover 浮现，激活态 `#1868AD`）、右「字数统计 + 光标段落类型」。模式入口三处并存：视图菜单勾选、快捷键（F8/F9）、页脚按钮。
- **字数口径**：默认「字数」= **中文字符数 + 英文单词数**（不含空白）；点击弹出明细浮层（字数/字符/段落/行数四口径），选中口径**持久化到设置**。
- **数据与性能**：渲染层从 ProseMirror doc 遍历统计（不动引擎）；输入停顿 200–300ms 防抖刷新；光标段落类型实时跟随 selection（heading→「标题 N」、codeBlock→「代码块」、blockquote→「引用」、list→「列表」等）。
- **视觉**：字数常驻（12px、opacity .75、点击态背景 #eee）；模式按钮 hover 浮现；信息条 border-top 1px——全部吃主题变量。

## 8. 浮层重设计（票 08-find-panel-redesign）

- **搜索顶部条**：浮动卡片 → Typora 式**顶部通栏**（约 39px 高、输入框 26px 直角透明、12px、吃主题变量）；作用域「当前文件 / 整个工作区」双胶囊改为 **76px 下拉**；行为全保留——当前文件引擎 findInDoc 实时匹配、工作区 180ms 防抖主进程搜索、Enter 下一个 / Shift+Enter 上一个 / Esc 关闭并清除高亮；命中高亮换基线观感——**临时琥珀 `rgba(248,192,116,.3)` + 当前项黑底白字**；「视图 → 全工作区搜索 Ctrl+Shift+F」保留，行为改为「唤起顶部条 + 预选『整个工作区』」；**替换模式不引入**（新功能，留 v2 功能裁决）。
- **链接面板**：交互全部保留（编辑态/选区态预填、移除链接、Enter/Esc、焦点归还），样式并入主题；唤起方式 Ctrl+K + 格式工具栏第三组「链接」按钮。
- **代码块复制按钮**：悬停浮现交互保留（复制纯源码剥离行号、1.5s「已复制」），样式并入代码块整体视觉（与 §4 分工：§4 定视觉、本票定交互）。
- **横幅与对话框**：DocMissingBanner、ChangeNoticeToast、TextPrompt 全部并入主题变量（形态交互不变，三主题各自适配；Toast 深色底改用主题变量表达）。
