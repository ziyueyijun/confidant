# 07: 行内格式与浮动工具条、链接编辑

**What to build:** 选中文本即浮现浮动格式工具条(加粗 / 斜体 / 删除线 / 链接 / 清除格式,规格 9.5),就近浮于选区,失焦或空选自动隐藏;「格式」菜单与快捷键同步点亮(加粗 Ctrl+B、斜体 Ctrl+I、删除线、链接、清除格式——命令经 03 框架注册);不依赖语法、不依赖记忆,选中即见。

- 链接插入与编辑:浮动条「链接」给出设置地址(与可选显示文本)的小交互;单击已存在的链接进入编辑态(可改链接文本/地址),**不跳转**(防误触打断写作,规格 14);打开链接的跳转行为(右键「打开链接」/Ctrl+单击)在 16。
- 任务/表格等块级格式入口不在本票(段落菜单在 08/09/10)。
- 浮动工具条视觉细节与深浅色由 18 统一,本票保证功能与可用布局。

**Blocked by:** 03(菜单栏与固定快捷键框架)。

**Status:** ready-for-agent

- [ ] 选中文本即浮现工具条:加粗/斜体/删除线即时生效,链接唤起设置交互,清除格式还原;空选/失焦隐藏。
- [ ] 「格式」菜单各条目与 Ctrl+B/Ctrl+I 快捷键可用,与工具条同一命令源,生效一致。
- [ ] 选中含混排(部分加粗部分不加)的文本时,工具条状态正确(不误判全选态)。
- [ ] 单击链接 → 进入编辑态(改文本或地址),不触发跳转、不打断输入流。
- [ ] 行内格式改动保存后往返正确(保存→重开格式仍在;格式命令后撤销/重做在 08 接线后可用,本票不验收)。
