# 29: 移除浮动工具条,链接面板独立为弹层

**Type:** task
**Blocked by:** 无。
**Status:** resolved

**What to build:**

1. **移除浮动工具条**:选中文本时浮现的格式按钮组(加粗/斜体/删除线/链接/清除格式)整体移除;选中内容时编辑区不再显示边框(该边框即浮动工具条自身边框,预期随移除消失;若复验仍有边框,单独定位处理)。
2. **链接面板独立**:地址 + 显示文本输入、移除链接的编辑表单拆为独立弹层;触发入口:「格式 → 链接」(Ctrl+K)与光标停在已有链接内;保留提交(applyLinkEdit)/移除(removeLink)与面板内交互不丢编辑器选区/焦点。
3. 规格同步(浮动工具条条款);smoke 浮动条断言改为链接面板断言。

## 用户故事

1. 作为用户,选中文字时不再弹出任何工具条,编辑区干净。
2. 作为用户,需要插入链接时按 Ctrl+K(或菜单「格式 → 链接」),弹出独立面板填写地址与显示文本。
3. 作为用户,光标停在已有链接上时,可呼出面板修改或移除链接。
4. 作为用户,选中内容时编辑区不显示任何边框/轮廓。

## 实现决策(裁决记录,grill 访谈 Q5/Q8/Q10)

- 移除浮动工具条全部按钮(加粗/斜体/删除线/清除格式);这些命令仍保留于「格式」菜单与快捷键,无功能损失。
- 链接面板独立组件:模态弹层;保留原焦点保真行为(面板内点击不破坏编辑器选区,输入框可聚焦);打开链路:菜单命令 Ctrl+K → 面板;光标在链接内时同样可触发。
- 选中边框:预期即浮动工具条边框,随移除消失;实机复验仍有边框时(候选:Chromium 默认焦点环)再定位,必要时请用户截图。
- 快捷键与菜单结构不变(「格式 → 链接」Ctrl+K 已存在)。
