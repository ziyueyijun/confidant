# 28: 代码块增强(高亮/复制/换行/行号)与设置菜单

**Type:** task
**Blocked by:** 无。
**Status:** ready-for-agent

**What to build:**

1. **语法高亮**:lowlight(highlight.js)装饰层高亮,主题跟随应用深浅色;无语言标记的代码块不高亮;只影响渲染,不触碰磁盘字节与序列化。
2. **快速复制**:悬停代码块右上角出现「复制」按钮,点击复制纯源码(不含行号)。
3. **自动换行**:默认开启(pre-wrap),可关闭(横向滚动)。
4. **行号**:默认显示(CSS 计数器),可关闭。
5. **设置菜单**:新增顶级「设置」菜单 →「编辑器」子菜单,含两个勾选项:代码块自动换行(默认开)、代码块显示行号(默认开);持久化到 state.json 新键(editorSettings,不升版本,旧文件合并默认);smoke 顶栏断言同步加入「设置」。

## 用户故事

1. 作为用户,```js 围栏代码块按语言高亮,深/浅色主题下都清晰可读。
2. 作为用户,无语言标记的代码块保持无高亮(不误判)。
3. 作为用户,悬停代码块出现复制按钮,一键复制源码且不带行号。
4. 作为用户,长行代码默认自动换行,不横向滚动。
5. 作为用户,在「设置 → 编辑器」关闭自动换行后,代码块改为横向滚动。
6. 作为用户,代码块默认显示行号,可在「设置 → 编辑器」关闭。
7. 作为用户,设置修改后重启应用仍然生效。

## 实现决策(裁决记录,grill 访谈 Q7)

- 高亮:CodeBlockLowlight(官方扩展,装饰层),语言集采用 highlight.js 常用子集(实现时定清单,后续可扩);主题色接现有 CSS 变量体系(深浅两套)。
- 行号:CSS 计数器方案——把高亮后的 HTML 按行包 span(hljs 词法不跨行,按 \n 切分安全);行号位于 CSS 层,复制取 code 文本自然不带行号。
- 复制:悬停显隐的轻量交互;写剪贴板用渲染层可用通道(navigator.clipboard,受限时经主进程剪贴板 IPC)。
- 设置:扩展 AppStateV1 新键(沿用不升版本合并默认);菜单模板/命令注册表/上下文机制沿用现有;勾选即时生效 + 防抖落盘(与现有 state 写入一致)。
- 换行/行号只影响渲染层样式与装饰,引擎序列化路径零改动。
- 打印/PDF 宿主:继承高亮(装饰层若复用编辑器样式);行号在打印宿主的表现以实机复验为准,首版不承诺。

## 测试决策

- **最高 seam = 引擎公共面**:lowlight 高亮在引擎层验证(装饰产生、文档结构不变);roundtrip/normalization 矩阵不回归(代码块语言往返已有用例)。
- 渲染层:设置读写(hook 级,mock window.confidant)、菜单模板断言(新增「设置」顶栏)。
- state-store:新键合并默认值逻辑测试(沿用现有 state-store 测试方式)。
- smoke:顶栏断言更新;代码块截图(高亮效果/行号/复制按钮);E2E 竖切回归(代码块文件往返字节不变)。
- 验收:typecheck / 单测 / boundaries / smoke / E2E 全绿。

## 范围外

- 代码语言自动探测;源码模式内的高亮/行号;高亮主题自选;行号在打印/PDF 导出的保证;设置对话框化(菜单勾选即够)。
