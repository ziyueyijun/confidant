# 11: 树内拖拽移动与操作撤销

**What to build:** 文件树内拖拽移动文件/文件夹(含跨文件夹,规格第 8 节);移动完成后提示条「已移动 — 撤销」(单步),撤销即还原原位置;拖拽目标不合法(移入自身/自己的子孙、目标重名冲突等)按系统规则提示、操作不生效。

- 移动的是正在编辑的文件时:编辑区继续指向该文件(路径随移动更新),后续自动保存写向新位置,不打断写作。
- 撤销中心扩展(10 建立的通知条机制):把「移动」注册为可单步撤销的变更操作;删除仍不设撤销。
- 拖拽仅限树内;工作区外文件拖入(外部导入)不在本票(图片拖入编辑区在 05;外部 .md 导入未裁决,不做)。

**Blocked by:** 10(文件管理操作——通知条/撤销机制与文件移动语义)。

**Status:** ready-for-agent

- [ ] 树内拖拽移动文件与文件夹(同级、跨文件夹)成功,目标位置正确,树即时一致。
- [ ] 移动完成后提示条「已移动 — 撤销」,撤销一次即还原原路径(含跨文件夹还原)。
- [ ] 非法目标(移入自身或子孙文件夹、与目标重名冲突)被阻止并提示,操作不生效、树状态不变。
- [ ] 移动正在编辑的文件:编辑不中断,继续编辑/自动保存写到新位置;撤销移动后编辑区仍指向还原后的路径,不出现保存到已不存在路径的窗口。
- [ ] 移动后保存→重开:文档位于新位置,内容完整(旧位置不再有该文件)。
