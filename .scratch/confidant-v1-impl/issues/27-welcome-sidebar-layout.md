# 27: 欢迎页空态/侧栏无工作区可用/内容区宽度

**Type:** task
**Blocked by:** 无。
**Status:** resolved

**What to build:**

1. **欢迎页移除最近打开列表**:未打开工作区时仅显示产品名 + 标语行(纯空态,无任何按钮与列表);「文件 → 最近打开」菜单保留(与欢迎页同源数据,底层 recentFolders 记录不动)。
2. **侧栏无工作区可用**:未打开工作区时「视图 → 侧栏显示/隐藏」与顶栏 ◀/▶ 按钮仍可点击;侧栏以空态框体渲染(提示「尚未打开工作区」);显隐/宽度记忆已有(state.json sidebar 键,切换即存)——若实测记忆不生效,按缺陷修复。
3. **内容区宽度**:内容列上限约 860px、居中,两侧留白自适应(≈视口 20%,下限 16px);front matter 块与打印宿主同步同宽;规格 §12 同步。

## 用户故事

1. 作为用户,启动应用看到干净的欢迎页(产品名 + 标语),不陈列任何历史。
2. 作为用户,想打开最近的工作区时,从「文件 → 最近打开」菜单选择,入口始终可用。
3. 作为用户,未打开任何工作区时也能切换侧栏显隐,侧栏显示空态提示而非消失。
4. 作为用户,重启应用后侧栏显隐/宽度保持上次状态。
5. 作为用户,在宽屏上正文列不超过约 860px,两侧留白约 20%;窄窗口时留白不挤压到 16px 以下。

## 实现决策(裁决记录,grill 访谈 Q4/Q5/Q6 与 Q11)

- 欢迎页:删除最近列表渲染与对应测试标记与回调 prop;recentFolders 记录、菜单子菜单逻辑全部保留。
- 侧栏:菜单置灰规则放宽(不再要求已打开工作区);顶栏按钮渲染条件放宽;无工作区时渲染空态侧栏(复用现有侧栏框架);记忆复用现有 hook 与 state.json。
- 宽度:编辑器宿主样式改为 `max-width` 上限(约 860px)+ 自适应留白公式;front matter 块与打印宿主同规则;行高/字号/滚动结构不变。
- 不加侧栏快捷键(裁决:菜单入口已足够)。
- 规格 §6(欢迎页)、§12(布局)同步。
