# 08: 块级段落命令与撤销重做

**What to build:** 「段落」菜单整体点亮(规格第 7 节):标题 1–6 / 正文、无序列表、有序列表、任务列表、引用、代码块、表格(插入)——块级操作的菜单入口,不依赖语法、不依赖快捷键;「编辑」菜单的撤销 Ctrl+Z / 重做 Ctrl+Y(Windows 惯例)点亮,覆盖文本、格式与结构变更的历史。当前选区在正文时命令作用于所在块,选中多块时对每块生效,光标在块内时对该块生效;表格内段落命令的置灰/无效逻辑随实现给出合理处理。

- 代码块:插入代码块围栏与语言信息保持往返不丢(能力基线含「代码块(围栏+语言)」;语言切换 UI 不在规格,不承诺)。
- 任务列表插入后即出现可勾选复选框结构(点击勾选/缩进交互在 09 立)。
- 快捷键固定清单:与 03 注册框架一致,其余块级命令不设快捷键(菜单即入口,规格快捷键清单仅列标题层级等?——以规格第 7 节快捷键清单为准,未列项不给键位)。

**Blocked by:** 03(菜单栏与固定快捷键框架)。

**Status:** ready-for-agent

- [ ] 段落菜单全条目可用:把当前块切换为标题 1–6/正文、三种列表、引用、代码块;「插入表格」生成空表格且光标可进入。
- [ ] 跨多块选中时命令对每块生效;块命令不依赖 Markdown 语法输入。
- [ ] 代码块围栏与语言信息:插入(或打开已有)→保存→重开,语言不丢。
- [ ] 撤销 Ctrl+Z/重做 Ctrl+Y 对文本输入、行内格式(07 之后)、块级变更(标题切换/列表转换/表格插入等)逐级生效;菜单「编辑→撤销/重做」同源。
- [ ] 快捷键与规格第 7 节清单一致,无自定义键位 UI。
