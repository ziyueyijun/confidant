# 14: 查找(当前文件)

**What to build:** Ctrl+F(编辑菜单「查找」,03 置灰位点亮)与文件树顶部搜索框(04 占位点亮)唤起查找面板,作用域 = 当前文件(规格第 11 节):输入即实时子串匹配,命中以行摘要列出,点击命中处 → 编辑区滚动定位并高亮。面板可收起/关闭(Esc),焦点还原自然。

- 高亮为临时视图状态(decoration 层),不写入文档结构、不随保存落盘、不进入导出(19 的导出按渲染所见即所得,但高亮属查找过程态,导出前清除)。
- 首版子串匹配,不做正则/选项面板(裁决出)。
- 命中计数与上/下一个导航:规格未裁决,给出顺手的当前命中标记即可(如高亮当前命中与其余命中),不与规格冲突。
- 全工作区作用域与跨文件结果列表在 15。

**Blocked by:** 03(菜单与快捷键框架)、04(文件树侧栏基座——搜索框位)。

**Status:** ready-for-agent

- [x] Ctrl+F 唤起面板(树顶搜索框聚焦同源),输入即出当前文件内命中行摘要;Esc 或面板按钮关闭后焦点/编辑状态正常。
- [x] 点击任一命中 → 编辑区滚动到该行位置并高亮命中文本;命中高亮在文档其余位置可见区分。
