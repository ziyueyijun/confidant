# 18: 外观主题与正文排版

**What to build:** 深浅两套观感与默认排版(规格第 12 节)。分层:UI 壳(菜单/侧栏/浮动条等)走 shadcn 变量体系;正文渲染区独立 CSS;两套观感同源色板变量(深浅各一套,对比度满足可用性,色值实现自定并记录)。「视图→外观」菜单点亮:**跟随系统 / 浅色 / 深色**——跟随系统即随 Windows 色系自动切换,手动三态覆盖。

默认排版设计(无用户开关,以下为默认参数,实现可按可读性微调并记录):

- 正文区:居中布局,最大宽度约 820px;行高 1.6–1.8(中文排版底线)。
- 字体:中文正文系统无衬线栈(如 "Microsoft YaHei UI"/"Microsoft YaHei" 优先,西文 "Segoe UI");代码等宽栈(如 Consolas 优先)。
- 标题:层级通过字号阶梯 + 加粗 + 间距表达;文档标题(首个 H1)起排版骨架。
- 表格、代码块、引用有独立底色/边框区分(深浅色各一套);图片行宽上限等比居中样式统一收敛到本票渲染 CSS(06 的基线样式收编,避免两套);硬换行、链接、选中态颜色纳入。
- 打印/导出恒浅色观感(19 消费此分层),不随系统深浅。

**Blocked by:** 03(菜单栏框架——「外观」子菜单项点亮接线)。

**Status:** ready-for-agent

- [ ] 系统为深色时应用自动深色、浅色时自动浅色;「外观」菜单三态切换即时生效并记忆(重启保持)。
- [ ] 壳 UI 与正文区在两种观感下各自协调(正文区样式不依赖壳变量,分层清晰;色板同源,单点维护)。
- [ ] 正文默认排版生效:居中 ≤820px、行高 1.6–1.8、中英文字体栈正确回退;标题字号阶梯与首个 H1 骨架可辨;代码/等宽内容走等宽栈。
- [ ] 表格、代码块、引用在深浅两套下各有可辨识底色/边框,对比度满足可读性;图片显示行宽内等比居中(06 场景回归)。
- [ ] 深浅切换不丢编辑状态、不闪烁失真、不破坏布局(表格/代码块长内容滚动正常)。
