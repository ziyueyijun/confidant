# 16: 跨文件链接跳转与锚点定位

**What to build:** 链接的「打开」行为(规格第 14 节):单击链接进入编辑态(07 已立,不跳转);右键菜单「打开链接」与 Ctrl+单击执行跳转,按目标类型分流:

- `http(s)://` → 系统默认浏览器打开;
- 指向**工作区内** `.md` 文件 → 应用内打开(切换视图,当前编辑内容已自动保存——02 语义,不丢);
- 链接携带标题锚点(`file.md#标题`)且目标在工作区内 → 打开后滚动定位到该标题;
- 其他本地路径(工作区外的文件/文件夹,包括工作区外的 .md)→ 在系统资源管理器中显示。

- 锚点定位规则:目标文件内首个标题文本匹配(实现自定对大小写/空格的处理并在票尾记录);无匹配标题时正常打开文件不定位。
- 被链接文件已被外部删除(12 语义)→ 打开时按 12 提示条处置,不静默。相对路径/绝对路径的链接都解析;解析基准 = 当前笔记所在目录(与 06 图片解析同一套相对路径语义)。
- 仅打开行为在本票;链接的创建/编辑在 07。

**Blocked by:** 02(自动保存——切换不丢内容的前提)、04(文件树/工作区文件定位)、07(行内格式与链接编辑——链接节点交互基础)。
