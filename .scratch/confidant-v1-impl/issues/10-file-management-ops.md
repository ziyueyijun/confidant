# 10: 文件管理操作

**What to build:** 文件操作命令(规格第 8 节),来自树右键菜单与菜单栏「文件」命令,同一命令源(03 框架注册):**新建笔记**(默认名「未命名笔记.md」,重名自动加序号;同一命令从欢迎页空态引导可达,空态引导文案在 04 已亮出)→ 新建后即在编辑区打开;**新建文件夹**;**重命名**;删除规则:单文件直接移入系统回收站(不弹确认),文件夹弹一次确认(默认文案:「删除文件夹及其中的全部笔记?文件将移入回收站」);删除正在编辑的文件先提示(用户主动删除,给出明确提示后再执行并关闭/清空编辑区)。

- 重名冲突:由系统规则提示、操作不生效;只读介质/被占用文件的写失败给明确提示。
- 建立「变更通知条」机制(操作后提示,如「已重命名 — 撤销」,单步);重命名/移动的撤销动作经此机制提供(重命名本票接入,移动在 11 接入);删除不设撤销(回收站是恢复通道)。
- 新建/删除/重命名后文件树与磁盘即时一致(04 监听反哺或操作直接更新,状态不二义);正在编辑文件的删除处置与外部删除(12)共用「文件不再可写」的处理路径。
- 图片等非 .md 文件不参与文件操作(树不可见);操作只针对树内可见项。

**Blocked by:** 04(文件树侧栏基座)。

**Status:** ready-for-agent

- [ ] 树右键与「文件」菜单均可:新建笔记 → 空笔记「未命名笔记.md」落在当前文件夹并在编辑区打开;重名自动加序号(未命名笔记 1.md…),文件名可正常编辑后保存。
- [ ] 新建文件夹出现在树中;空文件夹可展开/显示。
- [ ] 重命名:单文件/文件夹均可(树内直接编辑或对话框,实现自定),重命名后打开路径一致更新;重名冲突给出提示且操作不生效。
- [ ] 删除单文件:不弹确认,直接移入系统回收站(回收站可还原,文件不在原处);删除文件夹:弹一次确认(默认文案照规格),确认后连同内容进回收站;取消则不动。
- [ ] 删除正在编辑的文件:先提示;确认后文件进回收站、编辑区不再指向不存在的文件(清空或关闭,实现自定并记录),不残留指向旧路径的保存。
- [ ] 写失败场景(只读介质/文件被占用):明确错误提示,不静默失败。
- [ ] 重命名完成出现「已重命名 — 撤销」提示条,撤销一次即还原(单步);文件夹重命名撤销同样成立。
- [ ] 树/磁盘即时一致:新建、删除、重命名后树视图不残留陈旧状态。
