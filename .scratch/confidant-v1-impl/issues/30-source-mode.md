# 30: 源码模式(Ctrl+/)

**Type:** task
**Blocked by:** 无。
**Status:** ready-for-agent

**What to build:**

1. **入口**:「视图 → 源码模式」勾选项 + 快捷键 Ctrl+/;全屏切换 WYSIWYG 编辑区 ↔ 原始 Markdown 文本区。
2. **数据流**:切入源码 = 当前文档序列化为完整文件文本(头字节原样 + 正文引擎规范化,即保存口径)填入文本区;源码模式自动保存 = 文本区原文字节直写磁盘(不经引擎序列化);切回 = 文本区内容经现有解析路径(头拆拼 + 正文装载)重载;切换文件/关闭文档/打开新工作区时复位为 WYSIWYG。
3. **菜单上下文**:源码模式下 段落/格式/查找(Ctrl+F)置灰;保存、撤销/重做、剪切/复制/粘贴保持可用,撤销/重做转发文本区原生行为;工作区搜索(Ctrl+Shift+F)不受影响。
4. **保存管线**:复用防抖自动保存;关窗 flush、外部变更重载在源码模式下以文本区原文为准。
5. **规格同步**:更新视图形态条款(原裁决「不存在源码模式」反转)。

## 用户故事

1. 作为用户,按 Ctrl+/ 切换到整个文件的原始 Markdown 文本(含 front matter),所见即所存。
2. 作为用户,在源码模式下直接编辑原文,自动保存写盘字节级一致(不改写、不规范化正文)。
3. 作为用户,切回所见即所得,内容与源码一致(引擎解析往返无损失)。
4. 作为用户,源码模式下菜单只留下可用项,撤销/重做/剪切/复制/粘贴照常工作。
5. 作为用户,源码模式下切文件或关窗,改动不丢失(flush 生效)。

## 实现决策(裁决记录,grill 访谈 Q9/Q12)

- 形态:全屏替换,不分栏;文本区单色等宽字体,首版无语法高亮。
- 真相源:源码模式下文本区即真相源——保存与关窗 flush 直接写文本区全文(含 front matter 原字节);切回时经现有解析路径(头拆拼 + 引擎装载)重载,头与正文随解析结果更新。
- 菜单:视图 → 源码模式(勾选态)+ Ctrl+/(无既有冲突);上下文规则:段落/格式/查找置灰,保存/撤销/重做保持可用,撤销/重做命令在源码模式下转发文本区(document.execCommand('undo'/'redo'),Chromium 对 textarea 支持);剪切/复制/粘贴为 role 项保持原生。
- 管线:复用 save-pipeline 防抖;IME 组合期门控仅 WYSIWYG 生效;外部变更重载前先 flush 文本区;关窗 flush 同步覆盖源码模式。
- 复位:切换文件、关闭文档、打开新工作区时强制回 WYSIWYG。
- 不新增 IPC:写盘通道(原子写)与引擎解耦,渲染层现有 API 已够。

## 测试决策

- **最高 seam = 引擎公共面**:新增源码文本 → 解析 → 再序列化的幂等往返用例(头字节原样 + 正文规范化);既有 roundtrip/normalization 矩阵回归。
- 渲染层(jsdom + mock window.confidant):源码模式状态 hook——切入内容 = 头 + 正文;保存直写原文;切回重载;菜单上下文快照;切文件复位。
- 冒烟 E2E 竖切扩展:源码模式键入 → 保存 → 磁盘字节比对(含 front matter 与行尾原样);关窗 flush 变体在源码模式下复验。
- 验收:typecheck / 单测 / boundaries / smoke / E2E(含 flush 变体)全绿。

## 范围外

- 源码模式语法高亮与行号;分栏对照视图;源码模式内查找/替换;切换瞬间的内容 diff 提示;源码模式下外部变更冲突的合并策略。
