# 04: 文件树侧栏基座

**What to build:** 左侧文件树侧栏成为工作区的组织视图:打开文件夹后即显示其树形内容,单击文件即在编辑区打开(替换 01 的过渡选择入口)。文件夹全显、文件只显示 .md;隐藏文件与杂项(以 `.` 开头或系统隐藏属性)不出现;排序:同层文件夹在前,组内按名称升序(自然序);展开/折叠状态记忆,重开还原(与启动恢复同源,13 消费);当前编辑文件高亮,不在可见区时自动展开定位;侧栏可收起(有可见按钮,不依赖快捷键)、宽度可拖;工作区内没有 .md 时编辑区显示引导文案:「这个文件夹还没有笔记:右键左侧空白处可以新建,也可以把 .md 文件放进这个文件夹。」;树顶部预留搜索框位(激活在 14/15)。

- 外部变更即时反映:自动监听文件夹,外部增删改原位即时刷新(此监听为与搜索同源的基础设施;正在编辑文件的处置逻辑在 12,本票只保证树视图与磁盘一致)。
- 打开工作区事件写入「最近打开」持久化记录(上限如 10 条,13 做展示),为欢迎页/最近打开菜单供数。
- 打开文件 → 编辑区渲染由 01 通道复用;树内点击切换文件即完成「切换工作区文件」主路径(当前文件自动保存已由 02 覆盖,切换不丢内容)。

**Blocked by:** 01(应用骨架与最小编辑闭环)。

**Status:** ready-for-agent

- [ ] 打开文件夹后树显示正确:文件夹全显、仅 .md 文件、`.`/隐藏项不出现;同层文件夹在前、名称自然升序。
- [ ] 单击文件 → 编辑区打开该文件并可编辑;再点另一文件 → 切换(切换前内容已自动保存,磁盘不丢)。
- [ ] 当前编辑文件在树中高亮;折叠状态下自动展开并滚动定位到该文件。
- [ ] 展开/折叠状态持久化:重开应用后还原(与「上次工作区」同源,数据供 13 使用)。
- [ ] 侧栏可收起(可见按钮)并可拖宽,状态随会话记忆;树顶有搜索框位(占位禁用,文案「搜索笔记…」可先显示)。
- [ ] 外部变更(用另一进程/资源管理器增删改文件或文件夹)后树原位即时刷新,不重启不手动刷新。
- [ ] 空工作区:无 .md 时编辑区显示引导文案(默认文案照规格)。
- [ ] 每次打开文件夹写入最近打开记录(持久化,供 13)。
