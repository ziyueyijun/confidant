# 17: 粘贴语义

**What to build:** 粘贴分流(规格 9.2):

- **富文本来源**(网页/Word):按语义转换——标题、列表、粗体/斜体、链接等结构保留;内容经安全白名单解析,不引入脚本/危险 HTML(粘贴 HTML 清洗,事件属性/脚本/危险标签剥除)。
- **纯文本来源**:原样插入,**不把 Markdown 语法文本解析成格式**(同事发来的 `- 事项` 粘贴结果是文字,不是列表)。
- **剪贴板含图片数据**(截图等):走 05 落盘通道。
- **位图与文件路径同存**:图片数据优先(位图落盘);否则文件路径对象按扩展名判断:图片 → 落盘通道;非图片文件 → 插入指向该文件的链接文本(不复制文件本身)。

- 富文本中出现的远程图片引用:网络图已裁决出(不做下载、不做图床)——实现选择(丢弃或转为链接文本)记录在票尾,不得静默引入网络资源。
- 富文本样式级信息(字体、颜色等)不在语义承诺内,可降级;结构与文本不丢。
- 粘贴处内容纳入撤销/重做链路(08)。

**Blocked by:** 05(图片落盘通道——位图与图片文件的落盘分支)。

**Status:** ready-for-agent

- [x] 从网页/Word 复制(标题、列表、粗斜体、链接)粘贴 → 结构语义保留为对应格式;纯样式信息(字体/颜色)不承诺。
- [x] 纯文本复制(`- 事项`、`# 标题`、`**粗体**` 等)粘贴 → 原样文字,不解析成格式。
- [x] 粘贴含脚本/事件属性的危险 HTML → 清洗后无脚本、无危险标签/事件残留;保存后仍为合法 Markdown。
- [x] 剪贴板截图粘贴 → 经 05 落盘为图片文件 + 相对引用(与 05 验收一致)。
- [x] 位图与文件路径同存 → 位图优先落盘;仅文件路径时:图片扩展名 → 落盘;非图片文件 → 插入指向该文件的链接文本(不复制文件)。
- [x] 粘贴内容可一步撤销(08 链路);粘贴不弹窗、不询问。
