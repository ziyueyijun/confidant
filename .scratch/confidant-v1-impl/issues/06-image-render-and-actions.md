# 06: 图片显示与图片右键操作

**What to build:** 工作区内 .md 笔记里的本地图片引用渲染出来(规格第 10 节渲染与右键):相对路径按笔记所在目录解析,支持常见格式 png/jpg/jpeg/gif/webp(GIF 动图正常播放);图片显示最大宽度 = 正文行宽、等比收缩居中(渲染层行为,不改动源文件与源语法——行宽上限与排版体系最终归 18 统一,本票给可用基线样式)。图片右键菜单三项:**打开所在文件夹**(树不显示图片文件——这是 P1 找到图片的唯一应用内通道)、**复制图片**、**删除**(引用与图片文件一并移入系统回收站,弹一次确认,默认文案:「删除这张图片及其文件?将移入回收站」)。

- 复制/打开所在文件夹用系统能力(shell);删除 = 从文档移除引用 + 图片文件移入回收站,两处一致;删除操作走 02 管线持久化。
- 相对引用解析与 05 同一工具,不做第二套。
- 删除图片后树/磁盘即时一致(04 监听反哺);若删除的是磁盘已不存在的图片(引用悬空),给出合理处置(如仅提示引用已失效),不留静默错误。

**Blocked by:** 05(图片落盘通道——引用解析工具与图片文件语义由 05 建立)。

**Status:** ready-for-agent

- [x] 打开含本地图片引用的笔记(05 落盘生成或手工放入) → 图片按相对路径正确渲染;png/jpg/gif 等常见格式可见,GIF 动图播放。
- [x] 图片不超过正文行宽,等比收缩居中;深色/浅色下均可见(观感统一归 18)。
- [x] 右键图片弹出三项菜单;「打开所在文件夹」在系统资源管理器中显示该目录(图片文件被定位到)。
- [x] 「复制图片」把图片数据放入系统剪贴板,可在其他程序粘贴。
- [x] 「删除」弹一次确认(默认文案),确认后文档引用移除且图片文件进入回收站;自动保存后重开文档无残留引用。
- [x] 引用悬空(文件已被外部删走)时不崩溃,右键操作给出明确提示。

## 实现记录(06)

- 提交:feat(06)(分支 impl/confidant-v1)。

- 渲染:Image 扩展配 NodeView(显示层经注入 resolver 换源、文档 attrs 不动、序列化保留原始引用);资产协议 confidant-img://asset/<encoded 绝对路径>(主进程 net 读取,仅放行本地路径+图片扩展名;CSP 放行);引用按当前文档目录解析(与 05 同目录语义,resolveRelative 共用);远程/未知协议图一律不渲染不请求(网络图裁决出,右键给提示);反斜杠/盘符/UNC/./.. 分支单测覆盖。

- 右键(原生 popup 菜单通道):打开所在文件夹(shell.showItemInFolder)、复制图片(Electron 44 异步剪贴板 ClipboardItem,统一 image/png 写入)、删除(确认文案照规格 → 引用移除走自动保存 + 文件 shell.trashItem 入回收站;回收站失败给出明确提示);引用悬空(文件外部被删):菜单顶部禁用提示项 + 「移除引用」,不静默。

- 自动化证据:90 单测;真机竖切:粘贴图片落盘后 DOM 断言 img 以 confidant-img:// 渲染且 naturalWidth>0(真实加载);欢迎/单文件回归通过;边界 lint 0。
