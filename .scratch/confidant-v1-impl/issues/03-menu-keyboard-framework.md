# 03: 菜单栏与固定快捷键框架

**What to build:** Windows 桌面形态的常驻菜单栏成为全部全局命令的可发现性通道(命令承载基座,后续功能票只需向本框架注册命令)。菜单按规格第 7 节默认结构全量铺开:**文件**(新建笔记、打开文件夹、最近打开、保存 Ctrl+S、导出 PDF、打印、退出)、**编辑**(撤销 Ctrl+Z、重做 Ctrl+Y、剪切/复制/粘贴、查找 Ctrl+F、删除)、**段落**(标题 1–6/正文、无序列表、有序列表、任务列表、引用、代码块、表格)、**格式**(加粗 Ctrl+B、斜体 Ctrl+I、删除线、链接、清除格式)、**视图**(侧栏显示/隐藏、全工作区搜索 Ctrl+Shift+F、外观→跟随系统/浅色/深色)、**帮助**(关于)。

- 命令注册表机制:每条菜单项绑定(所属菜单位置、快捷键、启用/置灰状态、处理器);本票把「已实现命令」接入(打开文件夹、退出、关于),其余条目先置灰禁用、处理器为空,由后续票注册后点亮——快捷键固定清单与 Windows 惯例一致,不支持用户自定义键位(超范围,不做)。
- 「关于」对话框:产品名 confidant/知己笔记 + 版本信息。
- 单窗口系统装饰,退出 = 关闭窗口(自动保存已由 02 覆盖,无未保存态对话框)。

**Blocked by:** 01(应用骨架与最小编辑闭环)。

**Status:** ready-for-agent

- [x] 启动即见完整菜单栏,六个菜单与上述条目一一对应(检查清单逐一勾过)。
- [x] 未实现命令显示为置灰/禁用,触发其快捷键无副作用;已接入命令(打开文件夹、关于、退出)可用。
- [x] 注册表可用:任一新增命令(演示:保存 Ctrl+S 已由 01 提供,接「文件→保存」)注册后菜单项自动点亮并响应快捷键。
- [x] 关于对话框显示产品名与版本;退出关闭窗口。
- [x] 快捷键固定清单落定并文档化(本票记录清单,供后续票接线),无自定义键位 UI。

## 实现记录(03)

- 提交:feat(03)(分支 impl/confidant-v1)。

- 架构:渲染层为唯一命令源——模板(market template,规格 §7 六菜单全结构)+ 命令注册表(menu-bridge.ts:每条命令 id 绑定启用规则与处理器,注册才可点亮,未注册一律置灰无副作用)+ 状态上下文(文档/撤销栈);native 菜单在主进程按模板构建(menu.ts),启用态经 diff 推送,点击经同一 command 通道回发渲染层执行。快捷键为模板 accelerator 固定清单(Ctrl+S/Z/Y/F/B/I、Ctrl+Shift+F;未列项不给键位,无自定义键位 UI)。剪切/复制/粘贴/删除走系统 role 项(原生剪贴板语义,17 票粘贴语义接管时复核)。

- 已接入命令:打开文件夹、保存(Ctrl+S)、撤销/重做(启用态随引擎历史实时)、关于(产品名+版本+Electron/Chromium/Node 版本)、退出(走关窗 flush 路径)。其余条目全部置灰待各自票注册。
