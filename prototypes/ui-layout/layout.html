项目规划文档

这是一个使用 CodeMirror 6 构建的 所见即所得 Markdown 编辑器原型。

核心特性

  • Typora 式真 inline WYSIWYG 编辑体验
  • 最小 diff 保真（未编辑区域字节级不变）
  • 文件夹 + 文件树 + 标签页的库管理
  • 磁盘上永远是纯 .md 文件

技术栈

经过调研和原型验证，我们选定了以下技术栈：

Electron + CodeMirror 6
├── 主进程：文件 I/O、监听
├── 渲染进程：编辑器 UI
└── Preload：安全边界

为什么选择 CodeMirror 6？

架构上保证往返零损：buffer 即原文，未编辑区域零字节改动。

虽然 CM6 有光标/widget 交互问题，但这是为了保持与 Typora/VS Code 工具链兼容而必须接受的工程代价。
