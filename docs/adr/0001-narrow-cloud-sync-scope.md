# 收窄「不做云同步/多端」的范围决议

v1 建图时把「云同步/多端」列为 Out of scope，理由是「与本地优先原则直接相抵（数据必须是用户自己管理的本地 .md 文件）」（[.scratch/confidant-v1/map.md:50](../../.scratch/confidant-v1/map.md)），规格也把「多端同步需求者」列为目标用户的反例（[.scratch/confidant-v1/spec.md:31](../../.scratch/confidant-v1/spec.md)）。

2026-09-14 决定**收窄**这条解释：它约束的是**把数据托管给第三方云服务**（数据离开用户的掌控、格式由服务商决定），不约束**用户自己拥有并管理的 WebDAV 服务器**。在 WebDAV 同步里数据仍是用户磁盘上普通的 `.md`，远端也只是这些文件的副本，用户可以随时带走、用任何工具打开。产品原则不变，只是澄清它约束的是数据的**所有权与格式**，不是**传输方式**。

## Consequences

- 「不做云托管服务」这条线保留：confidant 不提供、不运营任何存储服务，用户自带服务端。
- 远端内容以**明文**存储，不引入端到端加密——加密会让远端不再是「任何工具都能打开的普通文件」，与本次收窄的前提冲突。这一点在同步设置界面明确告知用户。
- 兼容性上只承诺已在绿联 NAS 实测通过，其余服务端登记为待验证清单，不阻塞收官。
