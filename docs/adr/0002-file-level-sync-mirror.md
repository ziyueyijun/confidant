# 同步采用文件级镜像，而非快照式整包

confidant 的 WebDAV 同步按**文件级**工作：远端目录是工作区内容的逐文件副本，每次同步只传变化的文件，远端上的 `.md` 与图片可以被任何 WebDAV 客户端直接打开与拷走。这直接来自产品已写死的承诺——「保存后的文件始终是标准、合法的 Markdown，任何工具可打开、可带走、可备份」（[.scratch/confidant-v1/spec.md:13](../../.scratch/confidant-v1/spec.md)）。

## Considered Options

- **快照式整包**：每次同步把整个知识库打包（压缩、可能加密）成一个时间戳命名的文件上传，远端是一堆版本包。优点是没有「冲突」概念——两端各传各的包，互不覆盖；实现也简单。
- **内容寻址对象仓库**：思源笔记走的就是这条（[dejavu](https://github.com/siyuan-note/dejavu)），内容定义分块、SHA-1 寻址、AES 加密，支持去重与多设备。它的 WebDAV 目录里看不到用户的任何文件，只有 `indexes/`、`objects/`、`refs/`。

## Consequences

- 远端保持**纯文件夹**：应用不往远端写任何自己的文件（清单、索引、版本目录都没有）。多机之间的状态推断靠每台机器本地的状态表（base hash）完成，不需要远端清单。
- 代价是必须自己处理冲突、删除传播与首次合并；快照式方案这些都不需要。这三块是本方案复杂度的主要来源。
- 快照式唯一明显的好处（多设备不互相覆盖）由 base 判定 + 保守合并覆盖，不需要用整包来换。
- 端到端加密在文件级模型下不可行（加密后的单文件不再是「任何工具可打开」的 `.md`），因此 v1 远端内容为明文。
