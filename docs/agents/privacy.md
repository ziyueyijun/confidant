# 机密与隐私

**本仓库是公开的。** 所有 issue、评论、代码、文档、提交信息都会被任何人看到，且会被搜索引擎与爬虫抓取。写任何东西之前，先假设它会永久公开。

## 绝不写入

- **绝对路径**：真实用户名、真实磁盘路径（形如 `盘符:\用户名\...` 或 `/home/用户名/...`）。用占位符 `<用户>` 或环境变量（`%USERPROFILE%`、`app.getPath('home')`）代替。
- **凭据**：token、API key、密码、私钥、WebDAV 地址里的用户名密码。`.mcp.json` 里用 `${ENV_VAR}` 引用而非字面值。
- **机器指纹**：可用磁盘容量、内存大小、CPU 型号与核数、操作系统内部版本号、机器名、MAC 地址、序列号。
- **第三方个人信息**：他人邮箱、姓名、社交账号——包括依赖包里上游作者的邮箱。
- **私人对话**：家人、同事、朋友的言论，以及任何未获同意可公开的往来内容。
- **第三方版权内容**：维基百科正文、书籍摘录、付费课程材料。语料与数据集不入库（已在 `.gitignore` 排除）。
- **截图中的隐私**：贴界面截图前检查任务栏、文件名、通知、其他窗口标题。

## 用中性描述代替

实测记录里，**环境描述通常是没价值的、而结论有价值**。所以要写的是结论，不是环境：

| 不写 | 写成 |
|---|---|
| 本机报可用 `<具体容量>` | `fs.statfsSync` 可用 |
| 带内部版本号与 SKU 的操作系统全名 | 操作系统主版本（如「Windows 11」） |
| 本机开启了长路径支持 | 实测环境开启了长路径支持 |

**例外：软件版本要写。** `Node v24.18.0`、`SQLite 3.53.4`、`better-sqlite3 13.0.3` 这类是复现实验的必要条件，保留。

## 依赖与产物

`.gitignore` 已排除 `node_modules/`、构建产物、日志、`.env*`。**调研用的语料与依赖也排除**（`docs/research/spikes/*.jsonl`）——它们体积大，且含第三方版权内容；脚本保留以便重抓。

## 提交前自查

```bash
grep -rn "ZSJ\|C:\\\\Users\|D:\\\\\|AppData" --include="*.md" --include="*.json" . | grep -v node_modules
```

**在建立新 issue 或写文档前跑一次。** 这个检查是廉价的，而泄露是不可撤销的——即使事后编辑，内容可能已被缓存或归档。
