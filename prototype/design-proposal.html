知己笔记 · 视觉提案

布局一格没动。改的是三件事：线怎么画、面怎么分、笔怎么握。下面每一块都是可以当场比对的——左边是现在，右边是提案。

面：从五层近似米色，收到三层

现在浅色模式有五个面（#FDFCFA / #F7F5F0 / #EDE9E0 / #E8E3D8 / #DDD8CC），但中间那一列、抬起面、纸面是同一个值——五个数在做三件事，还都只差 4%。 提案把它压成三层，每一层只有一个职责。

框
--sunk · #F1EEE7
两条侧栏、标签栏、三条工具栏、底部栏。所有"不是正文"的地方。
纸
--paper · #FBFAF7
正文那一块。读的地方只有这一个面。
浮
--float · #FFFFFF
弹窗、右键菜单、下拉。比纸更亮，加阴影——浮起来靠两层信号，不只靠阴影。

为什么这一条能去掉最多线：框和纸换了颜色之后，"工具栏与正文之间"那条 1px 分隔线就不用画了——面的变化就是分隔。 一条标签栏下边框、三条工具栏下边框、两条侧栏的竖边框、底部栏上边框，这些线全部撤掉。 而且顺带解决一个现存的毛病：现在中间的工具条是纸色、两边侧栏的工具条是灰色，三列本来精心对齐的那条横线，被颜色拆成了两段。

墨：三阶，并且 muted 只做元信息

现在的 muted #9C8F82 偏褐，落在一堆米色上会发浑。往中性方向拉一点，让它安静地退后，而不是发脏。

用法收窄：只给"活着的东西"

  • 链接
  • 光标
  • 未保存的小圆点
  • 同步正在进行 / 出错
  • 正文里当前选中的那一条（文件树、大纲）
  • 开关按钮的"开着"
  • 工具栏里被按下的格式按钮
  • 悬停
↑ 这三样改用墨色，朱砂不再承包所有"选中"
深色模式要一起改。现在是 Claude 那套冷黑（#151414 / #ECEDEE），而浅色是暖纸（#FDFCFA / #1A1714）—— 切一下主题，色相也换了，像换了个产品。提案把深色改成暖黑：#141210 / #1B1815 / #262220，文字 #E9E5DE。 关系不变（框最暗、纸上一档、浮再上一档），只是整个家族往暖里挪——它跟浅色模式才是同一个东西的两种光线。

圆角：不是调大，是分档

真正的问题不是"圆角太小"，是只有一种圆角：全应用 66 处 4px、8 处 6px、15 处 8px。 4px 在 24px 的按钮上只占 1/6，看上去就是直角——整个界面是同一块料切的。改成三档，档与档差 ×2，不是 +2px。

--r-sm · 4px
行内的小东西：行内代码、标签、勾选框。高度 ≤ 20px
--r-md · 8px
一切可点的东西：图标按钮、树里的行、标签、菜单项。高度 22–32px
--r-lg · 12px
浮起来或围起来的整块面：弹窗、菜单、代码块、图片
两条硬规矩：① 侧栏、编辑器、底部栏这些贴边的整块面不给圆角——纸是裁齐的，只有浮起来的和手里拿着的才收角。 ② 现在 --radius-*（CSS 里 18 处）和 Tailwind 的 rounded-*（TSX 里 89 处）是两套并行的系统，值刚好一样所以看不出来——改一套另一套不动。合并成一套，都读 CSS 变量。

图标：一支笔，一个网格，一条产品自己的规矩

现在是两种尺寸（工具栏 12px、侧栏与底栏 14px）配同一套 1.3–1.5 的描边，12px 那批实际渲染出来约 1.2px，在 1× 屏上是灰的。 提案统一到 16 网格 / 1.5 描边 / 圆头圆角，作画区留 1.5 白边——所有图标看起来一样大，是因为它们真的画在同一个格子里。

产品自己的那条规矩：工具栏上的图标，画的是这个按钮产出的东西的样子。
引用 → 就是正文里那条竖线加两行；行内代码 → 就是一对反引号夹着正文；源码 → 就是标记本身 #。 这条规矩一次修好三个坏图标，以后加按钮也有依据，不用每次凭感觉挑一个通用符号。

另外收掉三个重码：现在界面上有三个 ✕（关标签、收侧栏、清除格式），一个符号三种意思——清除格式换成划掉的 T。 代码块和源码原来都是 <>，12px 下分不出来——源码换成 #。

线：两档，而不是一档通吃

全应用的分隔线、外框、表格格、代码块、每个标签的右边——都是同一根 1px solid var(--border-color)。 线的粗细一样，就等于没有层次。提案只留两档，并且表格改成印刷表格：只要横线，不要竖线。
